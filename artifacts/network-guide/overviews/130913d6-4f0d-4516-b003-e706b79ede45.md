# IPv4协议

## IPv4网络层技术导读
本类解决IPv4地址规划与路由转发的核心问题：针对传统A/B/C类地址划分导致的地址资源浪费、骨干网路由表膨胀、地址枯竭等痛点，实现灵活的子网规划、高效的路由转发，以及相关配置故障的诊断。

核心概念关系：传统子网划分（基于RFC950、RFC1122）是早期针对类地址浪费的解决方案，将类网络的主机位拆分为「子网号+主机号」，但受限于固定类网络的范围；CIDR（RFC1519）对其扩展，废除固定类限制，用「IP/前缀长度」表示地址，支持可变长子网掩码（VLSM）与路由聚合，从根源缓解地址枯竭与路由膨胀；最长前缀匹配是CIDR架构下路由转发的核心规则，选择前缀最长的匹配路由项作为转发依据，三者构成从地址规整到路由决策的完整逻辑链。

推荐阅读路径：先掌握IPv4地址的基础规则（RFC1122）→学习传统子网划分的标准推演→理解CIDR的扩展逻辑→精通最长前缀匹配规则→实践子网与路由故障诊断。

排障入口：使用ICMP地址掩码协议、本地配置命令，排查子网掩码配置、路由项匹配异常等问题。
