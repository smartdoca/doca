# 传输层安全

## 本类解决的问题
传输层安全核心解决网络通信中数据窃听、篡改、身份冒充的安全风险，为客户端与服务器的交互链路提供加密保障与身份认证，其中TLS1.3是当前工业界广泛采用的高效安全标准，平衡了安全性与通信性能，适配HTTPS等主流加密通信场景。

## 核心概念关系
本类核心围绕TLS1.3的三大模块展开：**握手流程**是建立安全会话的基础，严格遵循RFC8446规范的消息顺序；**证书认证**是验证通信双方身份合法性的强制环节，与握手流程深度绑定；**0-RTT机制**是优化首次通信 latency 的可选性能手段，需明确其重放攻击风险的边界，三者共同构成TLS1.3完整的安全通信逻辑。

## 推荐阅读路径
建议按“基础规则→核心流程→优化机制”递进学习：先掌握握手消息的统一结构与必须遵循的规范规则，再推演1-RTT完整握手流程，最后理解0-RTT的设计原理与适用场景，过程中同步结合证书认证的校验规则加深理解。

## 排障入口
本类内容内置了通过抓包、日志排查握手与证书故障的实操方法，可直接对应实际部署中的通信异常问题定位。
