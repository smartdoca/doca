# 链路层技术

本类涵盖无线WLAN链路、有线二层链路两类核心技术方向，聚焦解决链路层共性及专项问题：一是混淆有线以太网与无线WLAN的技术本质差异；二是无线WLAN漫游故障（如乒乓切换、延迟过高）缺乏标准化排查方法；三是有线二层通信异常、广播风暴等基础故障难定位。

核心概念围绕IEEE 802系列标准形成逻辑链：有线分支以DIX/802.3为帧封装规则，从物理介质传输→MAC地址转发标识→IEEE802.1Q（VLAN）广播隔离，构成完整基础链路；无线分支以IEEE802.11为核心，分为PHY与MAC层，MAC采用CSMA/CA（区别于有线CSMA/CD），基本服务集（BSS）是最小工作单元，扩展服务集（ESS）支撑同SSID漫游，分为基本漫游（延迟~500ms）与快速漫游（802.11r，延迟10-20ms）。

推荐阅读路径：按有线二层基础（物理介质→帧规范→MAC/VLAN）→无线WLAN链路标准→漫游机制→故障诊断的顺序学习，构建从基础到专项的完整逻辑。

排障入口：有线类优先核查帧封装标准统一性（避免DIX/802.3混合部署）、是否存在二层环路/VLAN跨域配置；无线类优先核对漫游RSSI阈值（典型值<-75dBm）、链路重传率（>10%触发切换）、漫游类型是否匹配业务。
