# 地址转换

本类聚焦网络层地址转换技术，核心解决私网地址复用、公网IP资源不足的矛盾，支撑私网与公网的双向通信，适配多设备共享公网IP的场景需求。
核心概念关联：以RFC3022为规范，**Basic NAT**实现私网IP与公网IP的1对1映射（分静态手动绑定、动态会话触发分配），**NAPT（即PAT）**通过传输层端口复用单个公网IP，两者的正常运行依赖**连接跟踪机制**——通过软状态维护会话映射的生命周期（地址绑定、查找、超时解绑），报文转换需同步调整IP头、传输层头及对应校验和。
推荐阅读路径：从传统NAT基础机制的分类与差异入手，再学习连接跟踪的会话管理逻辑，最后掌握报文翻译的细节规则。
排障入口：针对NAT表状态、连接跟踪超时、端口冲突及报文头修改错误等问题，可参考对应实操诊断方法。
