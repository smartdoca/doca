# 新型传输协议

本类核心解决现有TCP传输的队头阻塞、连接绑定IP/端口导致的迁移不灵活、并发流隔离性差等问题，聚焦QUIC这类下一代传输协议的核心机制落地，适配HTTP/3等高性能多请求场景。

核心概念关联：QUIC以连接ID（CID）为连接标识，摆脱IP/端口绑定；连接内支持多独立流（双向/单向），替代TCP单一全局流；流级与连接级流量控制分工保障接收缓冲区安全，无连接迁移依托CID实现客户端自主切换网络。

推荐阅读路径：先理解QUIC对TCP痛点的优化定位，再深入核心的流机制（含类型、状态、与TCP差异）、无连接迁移规则，最后掌握拥塞控制与TCP的协同逻辑。

排障入口：排查流冲突需依据RFC9000 §2.1的流ID唯一规则，迁移失败核查客户端主动迁移的操作边界（仅客户端可迁移），流量异常需核对流级（MAX_STREAM_DATA）与连接级（MAX_DATA）的参数通告逻辑。
