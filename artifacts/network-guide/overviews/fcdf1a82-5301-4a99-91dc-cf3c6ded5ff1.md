# 外部网关协议

本类解决跨自治系统（AS）间的路由可达性与路径选择问题——当内部路由协议（如OSPF）无法支撑不同管理主体网络互联时，外部网关协议（EGP，核心为BGP）成为跨域路由的核心标准方案。

核心概念关系：自治系统（AS）是BGP的基础单元，由单一主体控制、对外呈现统一路由；BGP作为AS间路由交换协议，通过UPDATE消息携带路径属性与可达信息，路径属性（如ORIGIN、AS_PATH）是路由决策的核心依据；EBGP（跨AS会话）与IBGP（同AS会话）是两类关键交互模式，二者对路径属性的修改规则（如AS_PATH仅给EBGP prepend）直接决定路由正确性。

推荐阅读路径：先理解**AS的核心角色（RFC4271定义）**，再掌握路径属性分类与关键机制，最后学习路径属性修改的实例推演。

排障入口：针对BGP路由异常，可从EBGP会话的AS_PATH规则、IBGP下NEXTHOP可达性、路径属性传递规范（RFC4271）三个维度排查。
