# TCP可靠性

本类聚焦传输层TCP协议的核心可靠性机制，解决**不可靠IP网络中实现有序、无丢失、无重复数据传输**的关键问题，覆盖从基础跟踪机制到故障诊断的全链路可靠性逻辑。

核心概念关系：以「全局连续字节序列」和「累积确认」为两大核心设计假设，所有机制围绕这两点构建：TCP序列空间变量（发送侧SND.UNA、SND.NXT，接收侧RCV.NXT、RCV.WND等）是跟踪数据位置与窗口边界的基础；确认号通过累积反馈接收进度，重传机制（超时重传、快速重传）应对数据丢失，滑动窗口流量控制则平衡收发速率、避免接收缓冲区溢出，全部逻辑严格遵循RFC9293规范。

推荐阅读路径：先整体理解TCP可靠性的核心假设，再深入学习序号、确认、重传、流量控制的规则，最后掌握Wireshark、ss等工具观测TCP传输问题的方法，建立从原理到实践的完整认知。

排障入口：优先参考工具观测章节，通过分析报文字段（序号、确认号、窗口值）、重传触发逻辑，定位TCP传输中的丢失、延迟等常见问题。
