# TCP基础

本类解决网络通信中TCP连接建立/关闭流程混淆、状态转换模糊的问题，帮助学习者掌握TCP可靠性机制的底层逻辑，具备排查SYN洪水、TIME-WAIT溢出等常见网络异常的能力。

核心概念关系：以传输控制块（TCB）为状态维护核心，SND.UNA、RCV.NXT等字段驱动TCP状态机转换；三次握手同步初始序列号（ISN）保障连接有效性，四次挥手利用半关闭特性实现全双工独立关闭，重传定时器（RFC6298）保障报文可靠性，状态机是上述机制的规则框架，安全边界（如SYN攻击）是协议需防护的场景。

推荐阅读路径：优先学习TCP连接建立与关闭的报文交互逻辑，再理解11个核心状态的转换规则，接着掌握重传定时器的工作机制，最后结合Linux工具学习异常诊断方法。

排障入口：针对SYN洪水、TIME-WAIT溢出等异常，可通过`ss`工具查看TIME-WAIT状态数量，用`tcpdump`抓取SYN报文分析半连接队列情况，依据RFC9293约束定位问题根源。
