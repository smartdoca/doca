# 传输层技术

本分类聚焦网络传输层技术体系，解决不同通信场景下的传输需求痛点：包括TCP连接状态混淆、可靠性保障、性能瓶颈问题，UDP轻量场景优化需求，以及QUIC对TCP缺陷的适配优化问题。

核心概念关系围绕各协议设计目标展开：TCP以传输控制块（TCB）状态机、序号确认、拥塞控制为核心，实现可靠有序传输；UDP基于无连接、8字节固定头报文设计，适配实时小报文场景；QUIC以连接ID、多独立流为核心，解决TCP的队头阻塞与IP/端口绑定迁移问题。

推荐阅读路径：先学习TCP基础知识（连接建立/关闭、状态转换）→ 深入TCP可靠性机制（序号、重传、流控）→ 掌握TCP性能优化（拥塞控制）→ 学习UDP协议规则→ 最后了解新型传输协议QUIC。

排障入口：TCP异常（SYN洪水、时延）用ss、tcpdump分析；UDP问题核查RFC768校验和；QUIC故障核对流ID、迁移规则。
