# HTTP/1.x

本类解决传统HTTP/1.0短连接模式下，TCP握手开销大、高并发性能瓶颈，以及HTTP消息边界无法正确解析的核心问题，是理解早期HTTP协议优化的关键。

核心概念关系：持久连接是HTTP/1.1的基础特性，替代HTTP/1.0的短连接大幅减少TCP交互；管道化是持久连接的性能优化，通过复用连接实现请求连续发送，但存在队头阻塞局限；消息边界（Content-Length/分块编码）是HTTP/1.1消息解析的核心，需与连接状态配合保障消息完整性；同时需关联请求走私等安全风险的防护。

推荐阅读路径：从持久连接规范与HTTP/1.0差异入手，再学习管道化机制与局限性，最后掌握消息边界识别与安全防护，循序渐进理解HTTP/1.1核心优化。

排障入口：针对HTTP/1.1常见问题，如连接未复用（Connection头设置错误）、管道化失效（请求/响应顺序混乱）、消息解析错误（Content-Length不匹配）、请求走私排查等。
