# 安全协议

本知识分类聚焦网络通信链路的安全防护，覆盖传输层与网络层两大核心安全维度，解决通信中数据窃听、篡改、身份冒充、报文伪造及边界防护不足等核心问题，支撑HTTPS、VPN等主流加密场景的安全通信需求。

## 传输层安全
本类解决客户端与服务器交互链路中数据窃听、篡改、身份冒充的风险，核心依赖TLS1.3标准，平衡安全性与通信性能。核心概念围绕TLS1.3三大模块：握手流程（会话建立基础，遵循RFC8446规范）、证书认证（强制身份校验，与握手流程深度绑定）、0-RTT机制（优化首次通信延迟，需明确重放攻击风险边界），三者构成完整安全通信逻辑。推荐按“基础规则→核心流程→优化机制”递进学习，同步结合证书校验规则加深理解。排障入口为通过抓包、日志排查握手与证书故障。

## 网络层安全
本类解决公网环境下报文被篡改、监听、重放、伪造的风险，支撑站点间VPN等场景，填补传输层/应用层安全的边界防护不足。核心框架为IPsec，组件含AH/ESP协议、安全关联（SA）、IKE密钥管理：AH侧重数据源认证与完整性，ESP兼具加密、认证、抗重放能力；SA为单向逻辑连接，需2个独立SA实现双向通信，分传输、隧道模式（网关需用隧道模式），遵循RFC4301规范。推荐先掌握IPsec核心机制，再结合VPN场景推演安全边界实现逻辑。排障入口为排查SA失效、模式选错、协议不匹配等问题。
