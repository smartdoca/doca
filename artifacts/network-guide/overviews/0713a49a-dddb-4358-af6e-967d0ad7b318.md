# 路由基础

本分类解决网络转发选路逻辑模糊、静态路由配置异常、路由同步故障等实际问题，聚焦网络层路由转发的核心基础机制，所有内容遵循RFC1122等标准规范。

核心概念关系：路由表是IP转发的路由条目存储与查找载体，最长前缀匹配（LPM）是路由表的核心查找优先级规则；静态路由是手动配置的特殊路由条目，优先级高于动态生成的缓存路由与默认路由；路由收敛是路由表在网络拓扑变化后，达到全网络路由表达一致、无环路的过程，是路由机制可靠运行的核心保障。

推荐阅读路径：先从RFC1122规范掌握路由表的最小必填字段、查找优先级等基础结构，再学习最长前缀匹配的选路逻辑与推演示例，接着理解静态路由的配置约束、适用场景与可重定向规则，最后掌握路由收敛的核心条件与工程实现要点。

排障入口：静态路由配置不通时，优先检查下一跳是否为本地直连IP；选路结果与预期不符时，核对最长前缀匹配的优先级规则；网络变化后流量异常时，排查路由更新是否完成收敛、环路避免机制是否生效。
