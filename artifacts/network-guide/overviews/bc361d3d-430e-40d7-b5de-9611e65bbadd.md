# TCP性能

本类聚焦传输层TCP的性能瓶颈解决，针对传统TCP在带宽利用率、时延匹配上的局限，以及如何通过拥塞控制机制提升传输稳定性与速率利用率的核心问题展开。

核心概念围绕拥塞窗口（cwnd）、拥塞阈值（ssthresh）、带宽时延积（BDP）、RTT构建：传统TCP遵循RFC5681规范，以cwnd与ssthresh的状态切换（慢启动→拥塞避免）约束发送速率，初始cwnd由SMSS决定，快速重传与快速恢复是丢包后的性能修复机制；BDP是链路最优吞吐量的参考，RTT决定速率调整周期；QUIC拥塞控制（RFC9002）是补充的优化方向。

推荐阅读路径：建议从传统TCP核心算法（慢启动、拥塞避免）的规则入手，理解BDP与链路吞吐量的关联，再结合工具学习性能监测方法。
排障入口：通过ss、tcptrace等工具观测cwnd变化、RTT波动与丢包事件，定位性能瓶颈（如cwnd不足、RTT过高导致的速率滞后）。

[TCP拥塞控制与性能优化](#/r/94da05aa-e2b7-43d3-a9ca-60223ea98c84)：掌握传统TCP与QUIC的拥塞窗口调整逻辑，计算BDP并理解其对链路吞吐量的意义，学会用工具分析TCP性能瓶颈，排查典型传输问题。
