# DNS基础

本类核心解决的问题：明确网络域名的分层命名规则、分布式权限委派逻辑、DNS查询的两种核心链路差异，掌握通过DNS工具观测解析链路的方法，为排查域名解析故障、理解互联网寻址底层逻辑提供基础支撑。

核心概念关系：DNS命名体系（树形结构、资源记录RR类型）是运行基础，定义了域名的层级规则与资源数据承载格式；区域委派是对全局命名空间的分片管理，实现分布式权限控制，避免单点维护瓶颈；递归查询（RD标志）是客户端到本地解析器的查询模式，由解析器完成后续迭代；权威查询是本地解析器到各级权威服务器的查询模式，两者配合完成完整解析，RR是各环节返回的核心数据载体。

推荐阅读路径：先学习DNS命名体系的树形结构与RR核心类型，再理解区域委派的分片规则与实现流程，最后掌握递归/权威链路的差异，逐步搭建DNS基础认知框架。

排障入口：重点关注委派边界规则、RD/RA标志位语义，通过标准DNS工具观测链路各环节的Referral响应，定位父服务器委派缺失、权威服务器数据异常等常见故障。
