# IPv6协议

### IPv6协议知识分类导读
本类聚焦IPv6网络层核心技术，解决IPv4地址耗尽、广播域冗余、网关易伪造等固有缺陷，为IPv6网络部署提供基础支撑。
#### 核心概念关系
IPv6地址体系是寻址基础：128位地址分为单播（全网/链路级）、任播（服务冗余）、组播（节点发现）三类，链路本地地址是NDP交互的强制基础；扩展首部机制优化报文处理（减少中间节点开销），分四类必需扩展首部并遵循固定处理顺序；邻居发现协议（NDP）依托链路本地地址完成邻居管理、重复地址检测（DAD），三者协同实现IPv6的寻址、转发与网络管理。
#### 推荐阅读路径
建议按「IPv6地址类型与规则→扩展首部机制→NDP流程→故障诊断」顺序学习，符合技术逻辑递进。
#### 排障入口
针对NDP邻居不可达、链路本地地址缺失、扩展首部导致的报文转发异常等场景，可基于本章内容定位故障点。
