# 无线链路

本分类聚焦无线局域网（WLAN）链路层技术，解决三类核心问题：一是混淆WLAN与有线以太网的技术本质差异；二是无法区分IEEE802.11链路层必需与可选行为，对漫游机制理解模糊；三是WLAN漫游故障（如乒乓切换、延迟过高）排查缺乏标准化方法。

核心概念关系：以IEEE802.11标准为核心，链路层分为物理层（PHY）与媒体访问控制层（MAC）；基本服务集（BSS）是WLAN最小工作单元，扩展服务集（ESS）支撑同SSID下的跨AP漫游；MAC层采用CSMA/CA（冲突避免）的无线介质访问机制，与有线以太网的CSMA/CD（冲突检测）形成技术分野；漫游基于ESS架构，分为基本漫游（需重关联认证，延迟约500ms）与快速漫游（802.11r预认证，延迟10-20ms）两类。

推荐阅读路径：按IEEE802.11核心框架→必需/可选链路行为→关键报文字段→WLAN与有线技术差异→漫游触发与流程→链路诊断方法的顺序学习，形成完整逻辑链。

排障入口：针对WLAN链路问题，优先核查漫游触发的RSSI阈值（典型工程值<-75dBm）、链路重传率（>10%触发漫游切换）、漫游类型是否匹配业务需求。
