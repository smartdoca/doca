# 网络进阶技术

本分类针对传统网络在大规模虚拟化多租户、差异化业务保障、一对多通信场景的核心痛点，提供高效分层、质量可控、资源优化的进阶网络解决方案。

## 解决的问题
- Overlay网络：破解传统二层VLAN仅4096个Segment的容量瓶颈、STP冗余链路带宽利用率不足50%、MAC表过载泛洪等问题，适配数据中心及容器网络；
- 服务质量（QoS）：解决平权转发导致语音/视频等时延敏感业务SLA无法落地的问题；
- 组播技术：消除一对多通信场景（如直播、金融推送）中全网广播带宽浪费、单播复制高负载的弊端。

## 核心概念关系
- Overlay：构建于Underlay底层路由网络之上，核心为VXLAN：VTEP负责Overlay与Underlay的封装/解封装，VNI（24位）实现租户隔离，逻辑二层网络隐藏底层细节；
- QoS：基于IETF DiffServ架构，经流量分类识别→调节器约束→DSCP标记→队列调度→拥塞管理全链路实现业务质量保障；
- 组播：IGMP协议完成主机组成员状态上报，PIM协议基于成员信息在路由器间建立组播分发树，配合实现定向数据传输。

## 推荐阅读路径
按“Overlay核心VXLAN→QoS DiffServ框架→组播IGMP+PIM机制”的顺序循序渐进，掌握各技术的分层逻辑与部署场景。

## 排障入口
各子分类提供对应实操指引：Overlay关注VXLAN链路连通性、QoS核查DSCP与队列状态、组播基于IGMP版本兼容性排查接收异常。
