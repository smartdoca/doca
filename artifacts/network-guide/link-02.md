# 无线局域网（WLAN）链路层机制与跨接入点漫游特性
## 学习目标
1. 说明IEEE 802.11 WLAN的基本接入流程，区分必需与可选的链路层行为；
2. 对比WLAN与有线以太网的核心技术差异与适用场景；
3. 解释802.11漫游的触发条件、核心交互流程及两类漫游（基本漫游/快速漫游）的区别；
4. 掌握WLAN链路层的可操作诊断方法，能定位漫游异常问题。

---

## 一、802.11 WLAN核心框架与必需行为
IEEE 802.11是WLAN的国际标准，其链路层分为物理层（PHY）和媒体访问控制层（MAC），基础服务集（BSS）是WLAN的最小工作单元，由1个接入点（AP）和多个终端（STA）组成；扩展服务集（ESS）是多个BSS的集合，支持STA在同一SSID下的漫游。

### 1.1 必需与可选行为的区分
根据IEEE 802.11-2020公开草案：
- **必需行为**：所有STA必须支持被动扫描（监听Beacon帧）、关联/重关联流程、CSMA/CA介质访问控制；
- **可选行为**：主动扫描（主动发送Probe Request）、快速漫游（802.11r FT）、邻居报告帧、802.1X身份认证。

### 1.2 关键报文字段表（必需字段标注）
| 字段名               | 所属帧类型       | 必需性 | 作用说明                                                                 |
|----------------------|------------------|--------|--------------------------------------------------------------------------|
| BSSID                | Beacon/Probe Resp | 必需   | BSS的唯一MAC标识符，区分不同AP覆盖的无线网络                             |
| SSID                 | 所有管理帧       | 必需   | 无线网络的名称，STA通过SSID关联到指定WLAN                               |
| RSSI                 | Beacon/Probe Resp | 必需   | 接收信号强度指示，单位dBm，用于判断STA与AP的链路质量                     |
| Capabilities Info    | Association Req  | 必需   | 包含ESS/IBSS能力、加密支持、快速漫游标识等属性                            |
| PMKID                | Association Req  | 可选   | 预主密钥标识符，用于802.11r快速漫游时的预认证密钥复用，减少认证延迟       |

## 二、WLAN与有线以太网的核心差异对比
WLAN与有线以太网同属链路层网络，但因介质特性差异，技术实现完全不同，如下表：

| 特性               | WLAN（802.11）                          | 有线以太网（IEEE 802.3）                |
|--------------------|-----------------------------------------|-----------------------------------------|
| 介质访问控制       | CSMA/CA（冲突避免，需等待DIFS/退避）    | CSMA/CD（冲突检测，碰撞后立即退避）      |
| 隐藏终端问题       | 存在（STA间无法互相监听，易碰撞）        | 无（交换机广播域内所有节点可监听）        |
| 漫游能力           | 需切换AP并保持链路，涉及二层/三层移动性 | 无原生漫游，链路通过交换机端口固定绑定   |
| 带宽特性           | 共享介质，单AP带宽随STA数增加下降        | 独占端口带宽，交换机点对点转发           |
| 安全接入           | 需加密/认证（WPA2/WPA3），空中暴露帧    | 有线接入受物理端口限制，仅需端口控制     |

**核心差异总结**：WLAN的无线介质广播特性导致其天然需要漫游能力，而有线以太网的物理隔离特性无需漫游；CSMA/CA的退避机制会随STA数增加导致性能下降，这也是802.11引入QoS增强（802.11e）的原因。

## 三、802.11漫游的核心机制与实例推演
漫游是STA在同一ESS内切换AP，保持链路连通性的过程，分为**基本漫游**和**快速漫游（802.11r）**两类：基本漫游需重新关联认证，延迟约500ms；快速漫游通过预认证密钥减少延迟至10-20ms，属于可选扩展行为。

### 3.1 漫游触发条件（工程实践数值）
1. 当前AP的RSSI持续低于`-75dBm`（工程阈值，不同环境可调整±5dBm）；
2. 新邻居AP的RSSI比当前AP高`5dBm`以上（避免频繁切换的乒乓效应）；
3. 当前链路重传率超过10%（丢包导致性能下降）。

### 3.2 漫游流程逐步推演（数值化实例）
**场景**：办公室部署单ESS（SSID=Office_2.4G），2台AP：AP1（BSSID=00:11:22:33:44:01，信道6）、AP2（00:11:22:33:44:02，信道11），漫游触发阈值配置：RSSI<-75dBm、邻居AP高5dBm以上。
1. **初始关联**：STA（MAC=aa:bb:cc:dd:ee:ff）接入AP1，当前RSSI=-72dBm，链路正常，重传率2%；
2. **触发扫描**：STA移动至AP2附近，AP1的RSSI降至-77dBm，触发被动扫描（监听Beacon），或主动发送Probe Request帧；
3. **邻居AP发现**：STA收到AP2的Beacon帧，解析RSSI=-68dBm（比当前AP高9dBm，满足触发条件）；
4. **漫游交互**：客户端根据扫描结果及实现策略进行认证/重关联；Reassociation Request 携带当前 AP 地址等信息，新 AP 分配新的 AID。不要求先向旧 AP 发送 Disassociation，也不存在固定200ms等待。802.11r可加速安全关联切换，但总时延取决于设备与配置。
5. **链路切换完成**：AP2验证身份后返回Reassociation Response帧，STA与AP2建立关联，IP地址保持不变，重传率降至2%，完成二层漫游。

## 四、WLAN链路层诊断方法（可操作命令）
诊断漫游问题需抓取管理帧、查看信号参数，以下为Linux平台的常用命令：
### 4.1 查看当前链路与漫游配置
```bash
# 查看WLAN接口的当前AP信息、RSSI、漫游触发阈值
iw dev wlan0 link
# 查看漫游触发的具体配置（阈值、乒乓门限）
iw dev wlan0 get roam trigger
```
**输出含义**：`RX signal: -76 dBm`表示当前AP信号强度；`roam trigger: 5`表示邻居AP需比当前高5dBm才触发漫游。

### 4.2 抓取802.11管理帧（漫游核心帧）
使用`tcpdump`或`wireshark`过滤管理帧，诊断扫描、关联异常：
```bash
# 仅抓取管理帧（Probe Request/Response、Beacon、Disassociation）
tcpdump -i wlan0 type mgt
# 过滤漫游相关的Reassociation帧
tcpdump -i wlan0 subtype reassociation
```
**异常判断**：若未抓取到Reassociation Response，说明AP未验证STA身份，可能是PMKID缓存过期。

### 4.3 扫描邻居AP列表
```bash
# 扫描所有可见AP，查看RSSI、信道、SSID
iw dev wlan0 scan | grep -E 'BSS|signal|SSID'
```
**异常判断**：若邻居AP RSSI均低于-80dBm，说明STA处于AP覆盖边缘，漫游效果差。

## 五、常见误区与安全边界
### 5.1 常见误区
1. **信号满格=网络正常**：2.4GHz频段同信道干扰严重，RSSI=-50dBm也可能因隐藏终端导致重传率超20%，需结合重传率判断；
2. **快速漫游=零延迟**：802.11r的认证延迟为10-20ms，虽远低于基本漫游的500ms，但仍高于有线链路的切换延迟；
3. **SSID 与移动性边界**：常规漫游发生在同一 ESS；802.11k/v/r 分别辅助测量、引导和快速切换，并不保证任意跨 SSID 保持地址。地址能否保持取决于二层子网、控制器隧道或额外移动性机制，不能仅凭同一控制器或启用802.11r推断。

### 5.2 安全边界
1. **漫游的二层安全风险**：未启用WPA2/WPA3时，Disassociation帧可被恶意节点篡改，导致STA断网；启用802.11w（管理帧保护）后，可防止此类攻击；
2. **PMKID缓存有效期**：802.11r的PMKID缓存默认有效期为2小时，过期后需重新认证，会导致临时断网；
3. **漫游负载限制**：单AP同时接入的漫游STA不宜超过20个，否则Beacon帧丢失会导致漫游失败，需调整AP的负载阈值。

## 六、自测题（含参考答案）
1. **机制理解题**：简述802.11 STA被动扫描的必需流程，说明Beacon帧中用于漫游触发的两个关键字段及其作用。
   参考答案：被动扫描是IEEE 802.11规定的STA必需行为，流程为：STA在工作信道上循环监听AP发送的Beacon帧，无需主动发送报文；关键字段为**RSSI**（当前AP的信号强度，用于判断链路质量是否恶化）和**邻居AP列表**（由IEEE 802.11k标准定义的可选Neighbor Report元素，携带邻居AP的BSSID与RSSI，减少STA的主动扫描时间）。

2. **对比应用题**：结合CSMA/CA与CSMA/CD的技术原理，说明为什么有线以太网几乎不需要漫游，而WLAN需要。
   参考答案：CSMA/CD是冲突检测机制，仅在有线共享介质中有效，碰撞后立即退避，且有线链路通过交换机端口点对点连接，链路质量稳定，移动性需求低；WLAN采用CSMA/CA（冲突避免），因无线介质的隐藏终端问题，碰撞后需随机退避，且AP覆盖范围有限，移动时信号会衰减至阈值以下，需切换AP保持连通，因此原生支持漫游。

3. **故障诊断题**：Linux主机执行`iw dev wlan0 link`后显示BSSID仍为AP1，但`iw dev wlan0 scan`中AP2的RSSI更高，请说明可能的原因及诊断命令。
   参考答案：原因是STA的漫游阈值配置为“邻居AP需比当前高10dBm以上”，但AP2仅比当前AP高8dBm，未触发漫游；诊断命令为`iw dev wlan0 get roam trigger`，查看当前漫游触发的dBm门限，若需调整为5dBm，执行`iw dev wlan0 set roam trigger 5`（参数依驱动版本而定）。
