# Doca

[English](README.md)

面向个人与小团队的文档知识库。

许可证为 [AGPL-3.0-only](LICENSE)。

这是应用程序仓库，不会作为 npm 包发布。容器镜像将是 `smartdoca/doca`。

编辑器包：

- [slate](https://github.com/smartdoca/slate)
- [sheet](https://github.com/smartdoca/sheet)
- [markdown](https://github.com/smartdoca/markdown)
- [canvas](https://github.com/smartdoca/canvas)
- [slides](https://github.com/smartdoca/slides)
