# 浏览器助手

[English](browser-assistant.md)

浏览器助手将网页选区或当前页面已加载的内容与图片保存到 Doca，并提供个人 AI 对话侧栏。入口为个人菜单 → **浏览器助手**，或 `/#/browser-assistant`。

## 安装与登录

1. 在「收录方案」设置保存目录，以及每次新建文档或追加到指定富文本 / Markdown 文档。标题模板支持 `{title}`、`{date}`；可以设置默认方案和 AI 整理要求。知识册生成页面不接受直接追加。
2. 点击设置页上方的「下载已配置扩展」并解压。Chrome / Edge 的扩展管理页中开启开发者模式，选择「加载已解压的扩展程序」。Manifest V3 最低要求 Chromium 116；ZIP 不能直接点击安装，当前未提供商店或企业签名分发。
3. 安装包只含 Doca 站点地址，**没有账户凭证和激活有效期**。打开插件时，已有 Doca 登录会话会自动完成授权；没有登录时打开 Doca 正常登录页，登录后返回插件继续使用。安装前已打开的网页刷新后会显示右侧工具条；从浏览器扩展入口收录时也会按需加载脚本。
4. 网站退出、会话过期或被撤销后，该网站会话绑定的插件授权也失效。单纯关闭 Doca 标签页不等于退出登录。同一浏览器切换账户时重新加载该账户的方案和 AI 状态；原账户的未提交任务按连接隔离，切换回来可以继续。

插件不读取或复制网站登录 Cookie。登录交接在 Doca 同源页面完成，使用 60 秒单次授权码和 SHA-256 校验的随机 verifier，换取 10 分钟的受限访问凭证。凭证只保存在扩展可信上下文的浏览器会话存储中，并自动重新验证；服务端只保存哈希，每次检查对应网站会话及连接状态。浏览器阻止扩展携带网站 Cookie 时，通过同源页面验证；后台被动轮询最多复用 30 秒内的同源验证结果，用户收录和 AI 操作会重新核对。

## 收录方案的保存位置

「每次新建文档」使用与文档移动相同的树形位置选择框。可选择「个人文档」、某个知识库根目录，或展开知识库，选择具体文档下方。知识库列表单独分页，不受最近文档数量影响；「加载更多知识库」继续显示下一页。选择方案保存后，再次打开会自动展开并定位到原来的位置。

选择器展示当前账号可写入的普通知识库，并保留库内目录层级；不能写入的文档置灰，仍可展开查看可写子节点。目录加载失败可重试，当前选择不会改成其他位置；失效或无写入权限的位置会阻止保存。超大知识库遵守现有目录接口的 10,000 节点上限，并显示提示。知识册生成内容仍不接受浏览器收录。「追加到指定文档」继续使用文档搜索。

## 收录、AI 和切换地址

普通网页右侧常驻四个入口：**收录当前页面、收录选中区域、Doca 助手、设置**。拖动顶部把手可以上下移动整组图标，位置会保存在本机，刷新、新开网页或重启浏览器后恢复；聚焦把手时也可使用方向键、Home 和 End 调整。设置下方同列的箭头可收起/展开工具条，收起后仍能拖动。读取位置缓存后再显示，避免初始跳位。选择网页文字不会额外弹出图标或工具栏。

点击收录图标，在气泡的自定义下拉框中核对收录规则和目标，再点击「确认收录」。选区收录需先选中文字；整页包含当前顶层 DOM 已加载的内容，包括视口之外的部分。默认预选 Doca 的默认规则，也可以切换其他规则。每次打开气泡会重新核对登录和规则；连接暂时失败可重试，未配置规则时提供设置入口。失败后在气泡中重试，或在扩展弹窗点击「重试上次收录」，沿用原请求及材料，不重复生成文档。未提交材料保存在当前浏览器会话，关闭整个浏览器后可能需要重新选择。更新或重新加载插件后，旧脚本会提示刷新当前网页。

点击「Doca 助手」打开浏览器右侧助手，使用与 Doca 相同的对话界面、模型选择、Markdown、进度和审批。打开助手不会调用模型；发送新消息时读取当前标签页的最新页面。切换标签、导航或网页内路由后，引用跟随当前页面，不需要勾选附加网页。单条消息重试仍使用原消息的材料。页面图片不支持或读取失败不阻断 AI 阅读正文；完整收录仍要求图片齐全。欢迎页提供收录网页、总结页面、提炼要点和整理收录四个提示。AI 使用 Doca 配置的模型、计量和审批流程，生成的会话可以在 Doca 中继续。连接默认可以使用 AI，用户可在 Doca 编辑连接名称及 AI 开关；实际请求仍受账户权限及模型策略约束。

新会话在首条消息被接收时，以网页名称、请求和域名生成标题，来源使用浏览器图标标识。新消息附加的网页进入「操作过的资源」，网站和插件中均可查看并在新标签页打开，同一网址只保留一个关联条目；这些链接不授予文档权限。规则修改后，上次会话若绑定旧规则版本，重新打开助手会使用当前选中规则的新输入器，旧会话和待发送消息保留；不会把旧任务自动改成新规则。既有标题和旧会话不回填改写。

当前扩展版本为 **0.2.4**。更新 Doca 后，需重新下载并在 Chrome / Edge 重新加载扩展；仅更新服务端不会更新已安装的插件。普通收录不需要 AI 模型，AI 侧栏需要站点已配置并允许使用的模型。

普通 HTTP(S) 网页在导航后或安装前已打开、尚无抓取脚本响应时，收录会在当前网页的顶层框架按需加载扩展自带脚本并重试一次，无需刷新网页。扩展为此声明 `scripting` 权限，继续使用已有的 HTTP(S) 站点访问范围；浏览器限制页面及被拒绝的站点访问仍会明确报错。

新的 AI 发送在清空输入器之前，先以事务保存到 IndexedDB，并按 Doca 站点、账户、连接及所选规则隔离。正在发送、发送失败及已接收的消息在对话中显示一次；待发送列表只显示等待发送的消息，不等待 AI 正式回复才消失。刷新后继续使用原消息 ID；后端已接受的任务先核对，不重新捕获网页或提交。原 localStorage 中的旧待发送消息保留原文，需逐条明确继续或撤回，并选择当前模型和范围。

点击右侧工具条的设置图标打开独立设置页，可进入 Doca 的收录规则设置，也可直接修改 **Doca 服务地址**，填写例如 `https://doca.example.com`，不含 `/api/v1`、其他路径或查询参数。扩展弹窗内也保留设置入口。也可以在 Doca 复制站点配置，再粘贴到插件的折叠配置区域。生产地址要求 HTTPS，本机回环地址允许 HTTP。切换后验证新站点当前登录账户；原站点的未提交任务不会自动发送到新站点。地址配置格式是严格的 `{ "version": 2, "origin": "https://doca.example.com" }`。

## 撤销与恢复

在 Doca「浏览器连接」中撤销一个连接或全部连接。撤销会使访问凭证及待兑换授权码失效，取消相关浏览器 AI 任务；网站仍登录也不会自动恢复该连接。恢复时必须在 Doca 点击该连接的「恢复连接」，然后返回插件重新连接。插件不会通过自动创建另一条连接来绕过撤销。

撤销、退出和更换站点均不删除已保存文档、原图或 AI 会话，也不能回滚已经提交的事务。普通网站发起的 AI 任务与浏览器任务分别管理；同一会话在 Doca 内继续的普通任务不会因插件连接撤销而取消。运行中浏览器任务的后续工具及提交检查当前网站会话，当前宿主会在退出后取消对应任务；其他执行器通过任务心跳及操作边界复查。

## 内容边界

收录保留语义文字、标题、列表、代码、链接、常规表格、来源链接和图片，不复刻网页 CSS 或交互。未加载的数据、分页、iframe、关闭的 Shadow DOM、虚拟列表、画布和视频不属于完整归档范围。静态 SVG 图片和内联 SVG 经本地清理后转为保留透明背景的 PNG；移除脚本和事件属性。依赖外部资源、内嵌 HTML、动画或无法渲染的 SVG 改为文字占位。

图片支持 PNG / JPEG / WebP / GIF。本次新收录的静态图超过 **4 MiB 或 2500 万像素**时，上传前自动压缩至不超过 4 MiB、最长边不超过 4096、总像素不超过 1600 万；保持原编码格式，保留 PNG / WebP 透明通道，并按 EXIF 方向处理。未超阈值的图片保留原字节。GIF、动态 WebP 和 APNG 不转成静态图，超过原有 20 MiB 或 2500 万像素上限时改为带原因的占位。已保存图片及重试时已上传的图片不重新处理。静态原始输入最多读取 64 MiB、解码前最多允许 1 亿像素。SVG 原始文件限 32 MiB，以限制扩展消息大小。SVG 输出最长边不超过 4096、总像素不超过 1600 万，再按 PNG 规则压缩。

服务端单张图片上限仍为 20 MiB / 2500 万像素，每次最多 100 张、合计 100 MiB；正文最多 512 KiB。新收录先完成图片预处理，再建立任务。不支持、无法读取或转换失败的图片，在原位置写入缺图说明、原因及原始 HTTP(S) 来源链接，正文和其他图片继续保存；blob/data 临时地址不写成永久链接。权限、配额及存储故障仍阻止保存。任务建立后，正文、图片清单和请求 ID 冻结，重试时仍要求清单内的图片全部上传。暂存任务 24 小时到期；清理只移除未绑定文档的对象。

扩展 0.2.5 继续使用既有 v1 收录协议和位图资产格式，不改数据库。用户已同意：已保存文档、已上传图片及历史失败任务保持原样；更新并重新加载扩展和原网页后，为旧失败页面重新发起收录。旧任务不自动转换或重发，仍按原到期规则清理；回退无需转换数据，并保留已有文档和任务。已暂存任务继续按原清单要求重试。

AI 仅开放当前方案范围内的有限检索、读取、收录和富文本 / Markdown 操作，继续检查账户当前权限。没有任意网络、脚本、插件工具或通用网页自动操作入口，网页文字不能扩大权限。

## 升级与开发

升级或回退前，先停止队列发送并关闭所有旧版 Doca 网页和浏览器助手，不同时运行新旧发送器。保留 localStorage、IndexedDB、已保留的墓碑及之后的数据。回退保持队列发送停用，不将新存储导回 localStorage，也不自动启用旧发送器；旧版缺少安全停用发送功能时，不能恢复旧队列发送。见[获批的保留与回退约定](verification/issue-tracker-2026-10-21/ai-pending-idb.md)。

首版上线前按用户确认替换了原先的一次性激活包和 180 天 token 方案：旧 v1 配置、激活端点和 token 不再接受，也不自动转换；已创建的方案、文档、附件、会话及原凭证记录保留。更新扩展后使用新站点配置并重新登录连接。服务端、Web 和扩展应同步更新；不提供旧认证回退或混用方案。

扩展文件位于 `apps/browser-extension`。`pnpm build:browser-extension` 将共用 AI UI 构建到本地 `generated/`，已包含在 `build`、`dev` 和 `dev:workspace` 中。服务端将固定扩展文件、本地构建资源及公开站点配置一起生成 ZIP，不加载远程脚本。源码部署和 Docker 镜像均需包含这些构建资源。当前 DDL 在原五张表之外增加两张空的网站会话 / 授权码表，不提升数据库兼容代际、不回填旧凭证。见[数据库升级约定](database-schema-evolution.zh-CN.md)及[登录改造验收记录](verification/browser-clipper-login-2026-10-21/README.md)。
