# 图片任务验收与返修

验收依据是正式用户原文和最新正式澄清。普通任务以身份、修改意图、
关键文字、场景内容和整体自然程度为准，不默认要求全部部位写实或逐像素复刻。
用户允许真人脸与插画身体、衣服混合时，不追加全身摄影要求。
明显错误角色、关键文字错误、矩形拼接、重复场景和畸形仍须报告。
明确的数量或参与者关系须逐个记录实际可辨实例、归属、位置与接触依据，
不能把要求复述成成功证据，也不能用其他参与者的部位凑足数量。
没有此类正式要求时，不追加身体完整可见、数量或动作阶段条件。

## 规划与验收精度

`image_scene_inspect` 独立读取冻结原页及同书直接相邻页，核对角色、动作、
跨页局部身体和适用要求。它使用视觉模型的真实用量，既不生图也不判定成品通过。
实际原页/传输字节、正式要求、账号、范围和模型均绑定；缓存复用前重验权限及来源。
返回内容是模型的观察与推断，不能把一次规划的角色判断当作事实权威。
后续原稿或独立验收揭示冲突时，应按完整用户要求重新核对，不沿用错误角色排除目标。
源故事已命名角色可依据叙事、面部特征和同书跨页连续性识别；用户照片中的未知
亲属对应仍须用户确认或明确标签，不能凭外貌猜辈分。

当前宿主验收调用必须明确选择 `semantic` 或 `native`，没有旧参数默认转换。
普通内容保留用 `semantic`：全页与必要身份参考满足全部适用要求后即可完成，
不因图片长边超过 1600 或历史生成带选区而追加整页原生细查。
历史生成提示中的逐像素保护、原人轮廓或全身写实不成为新的用户约束。
普通语义返修优先整页自然续改；免费重合成须先确认完整 raw 内容正确，
且覆盖修复确实能自然融合。一轮覆盖后仍有断头、残肢或明显接缝时应回看
已有候选、改变编辑方法，不能重复猜多边形把正确的人物裁坏。
`native` 只能引用仍适用的正式像素或字体、排版精度要求；保留原生覆盖检查。
明确的“解码后 RGBA 像素逐点一致”属于像素精度依据；同时引用普通原样导出
要求时，每个引用须真实且适用，并至少有一个明确精度引用。仅要求像素尺寸
一致不构成逐像素内容一致要求。
缩放语义预览不会被标注为原生像素证据。无法核实关键要求时仍不通过。
无修改目标页误改后，最新成品已明确验收失败时可用 `image_export` 免费恢复
冻结原页，恢复结果仍独立验收。已通过或待验收的当前成品不会被此操作替换；
旧成品、回执、累计尝试及费用保留，不用再次生图来近似重绘原稿。

原稿规划只列本页相关对象及要求，不重复整批标准。完成但结构无效的回复
最多允许两次新的计量聊天修正，重新读取同一原稿和正式要求，不把被拒回复
当成事实。额度、连接、中断、截断及来源变化不走这条修正路径。
最多三次真实聊天用量均保留，第一次有效即停止修正；修正规划不产生图片生成调用。
修正反馈标明具体字段，并带有大小受限、明确未经验证的上一份草稿供模型核实修正，
避免每次从头重写引入新错误；草稿不进入事实、用户标准或编辑授权。
一次列出相关来源关系或引用错误。规划只核对可见
内容和来源，不要求生成编辑坐标或邻页对象图；实际编辑工具分别验证选区。
这些规划输出仅为当前运行的建议，不从旧回复转换，也不改写保存的图片或任务。
规划及独立验收使用模型配置的输出预算；推理模型的思考和最终 JSON 共用此预算，
不再按预计 JSON 字数另设更小上限而截断有效结果。真实用量按厂商回包记录，
截断仍不视为合格，也不自动重试。
官方 Ark Seed 2.1 Pro 原稿规划复用验收已有的严格 JSON Schema 对接；来源 ID
与正式引用索引限定为本次真实输入的枚举。角色和要求的引文直接选择正式原文
片段或完整标准；长原文按句及长度拆出逐字片段，不改写正式文本、不把片段
作为新增要求，也不自动修补模型改写的引文。宿主仍验证 UUID、长度、对象关系和
逐字引用，不修补被拒 JSON 或 ID。服务拒绝严格输出时明确失败，不降级重试。

恢复整批任务时，历史候选按当前书册的页序验收；前页缺失或已经不合格时，
先让执行者处理该页，不提前规划后面的历史候选。本次新保存、展示或明确选择
的候选仍立即独立验收。全部页面的最终完成门禁、已有验收和费用记录不变。

## 返修跳出与候选择优

执行任务内按当前页、正式要求摘要记录不同成品的真实失败，
重复评价同一资产不增加轮次；新失败资产、预览或技术读取不表示质量改善。
三个不同成品仍失败时，下一次付费生成前必须比较已有成品。
`image_saved_candidates` 按明确顺序分页列出至多六个真实保存候选；
选择使用原有 `image_batch select`，完整查看后才能切换，随后仍须独立验收。
若比较后保留当前成品，也须完成同样的原页/成品两帧查看及后续轮次选择，
才能记录比较完成；不把普通的“已是当前图片”回执当作比较证据。
不默认最新版本最好，第一次已经满足要求即停止生成。

第五个不同成品仍失败时，先做最后一次候选比较，再停止继续付费返修。
已满足用户标准的候选可以交付；全部候选仍有核心问题则保留最好候选及未解决项，
不得将“最接近”自动标为“已合格”。
质量策略计数是当前执行的运行时状态；新正式要求可重新评估策略，
它不重置持久付费序号、未知结果或费用。批次完整完成门禁仍核对全部来源、页数和最新验收。

## 来源与历史成品

生成时的要求摘要属于不可变回执，与对应实际 raw 的摘要一致。
正式澄清使旧验收失效，但不会改变历史成品本身。
历史成品仍须证明同账号、会话、原始任务范围、原页、实际 raw 与保存字节；
按当前正式要求重新验收。新编辑的预览、绑定与提交仍必须符合当前要求，
不能复用澄清前的付费许可。没有修改历史回执、raw、图片、费用或已批准的持久格式。

单页累计付费上限仍由 `DOCA_AI_IMAGE_MAX_ATTEMPTS_PER_PAGE` 配置，默认 5，
支持任意正安全整数，进程重启后生效。该上限与质量跳出机制分别起作用。
