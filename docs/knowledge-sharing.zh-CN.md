# 问答机器人分享与权限

[English](knowledge-sharing.md)

文档与问答使用同一个 `PermissionDialog`、`ShareLinkSettings`、成员选择器和权限浮层行为。问答组件仅传入资源标识、接口前缀和支持的权限能力；不得复制一套近似面板。文档默认接口仍是 `/resources/:id`，问答适配接口是 `/knowledge/assistants/:id`。

问答存储独立：原有机器人保存直接成员、管理员和公开范围；`knowledge_bot_sharing` 保存链接总开关，`knowledge_bot_share_links` 保存链接，`knowledge_bot_link_members` 保存接受记录。链接只授予问答阅读能力，不能授予管理权限或原知识库权限。问答不提供文档的编辑、评论、子节点继承能力。

链接开关、人数上限、有效期、复制、记录、停用和撤销使用共同交互。停用或过期只停止新增加入；撤销使该链接的授权失效，保留其他直接授权和其他链接授权。成员移除清除该成员在本机器人下的直接授权和链接授权。公开范围单独管理，与链接分享开关无关。

邀请链接继续使用 `#/s/:token`，由共同的登录和接受邀请流程处理。后端按 token 查找问答链接，未匹配时交给文档链接处理；响应的 `kind: assistant` 将接受者导航到机器人问答页。预览不授予权限，接受后才登记；事务及链接版本校验防止并发占用超过人数上限。

权限和成员变更使用机器人 revision 防止覆盖其他管理员更新，链接变更使用独立 version。来源知识库的有效性继续在问答检索时校验，不因分享而放宽。
