# 视觉与选择控件

以用户提供的飞书截图作为颜色/层级参考，不引入飞书商标或外部字体资源。

- 主色 #3370ff，侧栏 #f5f6f7，内容白色，正文 #1f2329，次要文字 #646a73。
- 边框 #dee0e3，分隔线 #eff0f1，蓝色浅底选中态，轻量阴影与6px控件圆角。
- theme.css 提供统一色板；workspace.css 管布局，styles.css 提供基础样式。
- 全部业务下拉框使用 select.tsx；原生select仅作为隐藏的具名表单控件保留FormData，不展示操作系统默认菜单。
- 支持方向键、Home/End、回车、Esc、Tab、前缀查找、禁用选项及点击外部关闭；浮层可向上展开，滚动/窗口尺寸变化时收起。
- 弹窗内浮层留在对应dialog中，避免影响模态焦点范围。确认框中的复选框也使用统一蓝色勾选样式。

检查包括筛选实际生效、鼠标选项、弹窗选值和Esc分层关闭。tests/select.test.ts覆盖选项解析、禁用分组和表单初始值，未声称已完成所有读屏软件和移动端兼容性验证。

## 管理中心与复合控件

- 管理中心分为左侧模块导航和右侧内容区：数据概览、用户管理、登录与注册、文件存储、Hook。统计使用轻量卡片，用户用列表与状态标签，创建/启停确认使用站内弹窗；小屏模块导航横向收起，内容独立滚动。
- 搜索框只由外框承担focus-within边框，内部input不产生第二圈阴影或边框。目录树的选中/hover底色由整行承担，内部标题按钮保持透明。
- 知识库重命名与删除确认不使用浏览器prompt/confirm。封面设置有图片预览，头像支持上传预览后保存；业务界面不暴露云存储密钥。
- 管理功能未实现的 SSO 仍明确显示状态，不提供可保存的假配置。Webhook 由管理员登记回调地址，可以是本机或内网程序，事件在后台投递。

## 文档阅读与编辑布局

- 文档顶部为固定单行：标题、收藏、最近编辑人（纯文字），右侧为蓝色分享与权限、文档信息菜单、通知和用户头像。正文及底部全文评论在内部滚动，外层框架不滚动。
- 不叠加独立格式工具栏，使用编辑器自身的编辑交互。保存状态和在线用户收在文档信息菜单；内容评论入口在右侧，也可用 Cmd/Ctrl + Alt + M 为选区添加评论。
- 主导航宽 220px，视口不超过 1200px 时先收为 56px 图标栏，可手动展开目录。文档容器不超过 1050px 时隐藏大纲，小于 800px 时再自动收起右侧评论，手动展开时作为浮层显示。

## 文档搜索范围

内容搜索统一返回文档。弹窗中组合文档类型、归属、是否属于知识库和多个具体知识库；多选知识库使用带勾选的轻量浮层。知识库管理页不再按知识库标题搜索，改为“搜索知识库内文档”。空关键词默认最近访问，设置筛选后显示满足条件的文档。用户管理的账号查找不属于内容搜索，保持原功能。

- “更多”使用省略号图标；点击打开完整月份，点击日期查看有权限访问的文档活动。窄屏图标导航中保留日历入口。
- 瞬时操作反馈使用 `Feedback`，全局仅挂载一个 `FeedbackViewport`。提示浮于页面右上方，不参与正文布局；同一消息不要在弹窗内外重复渲染。
- `info` 蓝色、`success` 绿色、`warning` 黄色、`error` 红色，均配图标与关闭按钮，不能只靠颜色传达状态。信息和成功提示五秒后消失；警告和错误保留至关闭或状态清除。
- 成功与失败必须显式传递不同 tone，不能将接口异常也当作普通通知。文档同步恢复操作、等待审核等持久状态保留在原位置并采用对应语义色；输入草稿和重要恢复操作不得被自动消失的提示替代。
