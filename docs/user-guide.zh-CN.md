# 使用指南

[English](user-guide.md)

先阅读[功能与边界](features.zh-CN.md)，了解默认部署和独立插件的区别。完成[快速开始](quickstart.zh-CN.md)并登录，即可创建第一篇文档或知识库。管理员管理站点，资源的所有权和协作授权决定具体内容的访问权限。

## 文档与知识库

通过创建菜单新建富文本、Markdown、表格、幻灯片或画布文档。个人文档是独立页面；知识库提供目录，可以包含嵌套文档页面。新文档可使用已注册模板；[模板与素材](creation-resources.zh-CN.md)介绍来源选择和搜索。

在编辑器中插入图片和附件。保存状态以服务端持久化回执为准。网络中断或能力不受支持时，按界面状态处理；它不代表已经形成持久的离线备份。详见[实时协同](collaboration.zh-CN.md)。

文档菜单按权限提供分享、复制、移动、历史和回收站操作。副本有独立 ID；移动可能改变继承权限和公开范围，操作前检查目标位置。[文档与分享](document-experience.zh-CN.md)及[权限](permission-inheritance.zh-CN.md)说明具体规则。

## 分享与发现

可以设置资源阅读范围、邀请具名协作者，或创建分享链接。阅读、评论、编辑和管理是不同角色。公开知识库为其中页面建立阅读基线。系统管理员不会自动获得私有内容权限。

公开发现、个人收录、收藏和最近访问有不同用途。访问不会自动收录，收录不会授予访问权限，搜索会重新校验当前权限。详见[发现与收录](public-resource-discovery.zh-CN.md)。

## 文件、评论与通知

普通文件放在个人文件或共享文件夹中。下载经过授权，对象 ID 不是公开下载链接。文档可以引用文件，不需要公开物理存储目录。详见[文件存储](storage.zh-CN.md)。

评论按资源权限支持回复、提及、解决和通知。临时协同光标与永久评论锚点是不同的能力。[评论与通知](comments-and-community.zh-CN.md)说明可见范围和当前支持情况。

## 知识整理与 AI

[知识整理](knowledge-studio.zh-CN.md)把已授权来源组织成持续维护的知识库。问答助手检索有权访问的来源，[问答分享](knowledge-sharing.zh-CN.md)控制谁可以使用助手。

个人 AI 助手可以使用已授权的文档与文件。附加引用和会话审批可以限定范围，不会扩大你的账号权限。模型和服务是否可用取决于管理员配置。

## 账号与管理

在账号页修改显示名、头像和密码。修改密码会退出该账号的全部会话。站点管理员配置注册、身份源、AI 模型、搜索、插件和 Webhook，相关任务见[身份认证](authentication.zh-CN.md)与[插件部署](plugin-deployment.zh-CN.md)。
