# 文档能力与部署核对（2026-10-04）

基线：宿主 0.1.10、SDK 0.1.9。核对覆盖公开导航的 47 页中文与英文文档、根 README、环境示例、相关研发资料入口及残留代码。研发资料保留原文，历史结论只适用于原版本。

## 更正内容

| 范围 | 核对与更正 |
| --- | --- |
| 部署必填 | 区分 Compose、镜像、源码默认值。Compose 要求来源、文件存储 ID/JSON；示例已提供本地存储，首次单机仅改 HTTPS 来源。PostgreSQL、Redis、AI/SSO 凭据与插件凭证主密钥不是核心单机启动必填 |
| 代理与健康 | 默认不信任任何代理，包括回环；按实际连接来源配置可信 IP。生产本机探测须带正确 Host，否则返回 421；内置 Docker 探针已经携带该头 |
| 环境传递 | `.env` 只参与 Compose 插值，不自动传递全部变量；补充固定监听/数据路径与问答 iframe 允许来源的 override 方案 |
| 数据库 | Webhook 独立存储；PostgreSQL 默认主库名加 `_webhooks`，无建库权限需预建或指定独立 URL。AI 使用独立 SQLite 或 `doca_ai` schema，初始化需权限 |
| 当前产品 | 五种编辑器、知识整理、问答、认证和注册审批已实现。随手记已移出，邮箱/日历/会员/业务审核不默认安装；模板/素材/元素默认无提供者 |
| 评论与历史 | 五种格式都有评论锚点，表格使用稳定行列身份。五种格式可读历史，但仅富文本/Markdown 可恢复；其余 `canRestore:false` |
| 接口与文件交换 | 对照运行镜像 OpenAPI 核对主要路由；注册审批改为独立 POST 审核接口。补齐当前 PDF/PPTX 导入导出与安装包版本 |
| 插件 | 安装归档与注册记录共享，每实例缓存可写、重启生效。凭证及卸载失效已实现，集群业务任务排空与临时工作区仍未交付 |

## 清理范围

移除 3 个随手记 QA 脚本和已失效的自管邮箱包验收脚本；移除无引用的 imapflow、mailparser、nodemailer 与两项类型依赖；清理会员残留 CSS 和 6 组无引用双语字典项。账号测试更名为 `accounts.test.ts`，保留全部用例；保留阻止旧随手记、会员和审核 API/表回归的测试。

未删除现有持久表或数据，未修改兼容读写、锚点版本解析、数据库基线或迁移策略。核对发现当前持久 schema 仍含 `document_templates`，公开模板 CRUD 已退出；历史表的处理需要另行确认，不将删表作为代码清理。已更新的协同、文件交换和语言约定同步到项目与本机安装的 skill 引用。
