# 文件交换接入约定

[English](editor-file-exchange-contract.md)

适用 Doca 各编辑器的文件导入、导出和包升级。基础内容与可接受的样式优先，不要求完整 Office 还原；部分能力有损可以接受，但不能静默丢弃重要内容。这里规定职责与验收，不意味着每个包已实现全部接口。

## 职责

- 子包负责格式识别、解析/序列化、模型转换、素材枚举、结构化警告/错误、文件大小和解压/图片尺寸限制。以独立入口暴露纯转换器，声明 Node 或浏览器环境要求。
- 平台负责选择文件、创建新文档、授权上传和下载、用户反馈、文件名及触发浏览器下载。包不得自行连接平台 API、创建业务文档或开启第二条保存链路。
- 导入结果应为本机模型、待上传素材及警告。导出结果应为 Blob、文件名、MIME 及警告。具体字段以实际版本类型为准，不强制假定统一方法名。
- 支持类型由真实交付能力决定，文件后缀 accept 只用于提示，解析仍需验证文件内容。用户界面不提供 JSON 上传下载；内部模型及故障恢复副本不等于便携格式。

## 协同、素材与安全

- 默认导入创建新资源、新 epoch 和稳定身份；不将导入结果覆盖正在编辑的 Y.Doc，不复用旧评论、权限、历史和 outbox。全文替换必须另走明确的替换协议。
- 需要所属资源才能上传时，可先创建新记录、上传素材，再执行一次性初始化；服务端必须拒绝已初始化/已打开/已修改资源，不能让这个接口成为绕过协同的全量保存通道。
- 素材重新上传获得新文档自己的稳定 ID。不能持久化 blob/data/临时签名地址，也不能从导入文件信任已有用户、资源或权限 ID。外部资源默认不自动抓取；若支持抓取，宿主另行实现 SSRF/大小/来源限制。
- SVG 等主动内容必须安全处理。Doca 当前将已由画板包清洗的 SVG 栅格化后走原有图片上传服务；不直接放开同源任意 SVG 执行。
- 业务历史采用协同契约中的保留规则；淘汰历史行不代表素材已无引用，不据此直接删除附件。文件导出读取当前文档或仍保留的指定历史；已淘汰的版本明确返回不存在，不回退到当前内容冒充历史。
- 导出读取受当前资源权限约束；文件转换不改变正文、选区、撤销、presence 或保存状态，不等待/伪造 ACK。若包要求先结束原生编辑，宿主明确完成编辑后调用，不把 flush 隐藏在纯导出中。
- 取消、失败及迟到回调不得插入到其他文档/选区。服务端二次校验权限；中断上传不代表服务端资产已回滚，应说明临时资源清理策略。

## 按在线样式导出 PDF 与可编辑导入

富文本导出将当前本机模型的副本放入只读 portal，保留宿主语言、插件及文档上下文；不接入协同、不替换原编辑器、不结束当前编辑、不写 checkpoint。Markdown 挂载子包预览并使用编辑器相同的字体样式。两者等待图片、公式和图表，复制计算样式，内嵌经授权读取的平台图片和字体，移除编辑控件，再向 `POST /api/v1/resources/:id/pdf` 提交自包含页面。音视频保留可读说明和受权限约束的下载链接，附件及提及标签保留可读内容。PDF 文字仍可选择。纸张宽度沿用文档实际宽度，宽高比为 √2，上下打印边距 24 px；分页与连续在线页面可能不同。

宿主使用固定 WeasyPrint 70.0 的独立 Python 进程，不执行脚本，仅允许内嵌 data 资源；网络与宿主文件读取被拒绝，图片资源缺失或损坏时导出失败。渲染完成后仍二次检查 `read_content`，保留只读/公开权限规则、32 MiB 输入、两个并发任务、60 秒期限。AI 画板复用已安装 Canvas SDK 的 SVG 导出，在宿主适配的隔离 Node DOM 中用原生 Canvas 测量文字，再用 resvg 与随包中文字体生成图片；这是宿主适配，不表示编辑器包新增了 Node API。PDF.js 读取/导入、LibreOffice 转换保持独立。重新构建的 Docker 运行时使用 `node`，包含 Python/Pango/中文字体，不含浏览器，不依赖宿主 seccomp 文件。旧 `DOCA_PDF_CHROMIUM` 被明确拒绝，源码安装通过 `DOCA_PDF_PYTHON` 指定固定 Python 环境。SDK 已有历史读取规则保留原路径，不做数据库/文档转换或浏览器回退；回滚恢复原代码、锁文件和镜像，保留部署配置及后续数据。 含 HTML 标签的流程图以 PNG 保留浏览器布局，普通正文文字仍可选择；中文字体使用 TTF，避免逐任务解码 WOFF2。导出时不把 colgroup 的计算总宽误作为各列最小宽。

PDF 导入优先生成可编辑内容。已交付 Markdown 解析器继续校验文件、页数、图片限制，并提取素材与警告；宿主 PDF.js 适配补充字号、基础字体、粗斜体、文字颜色、安全链接、按字号识别的标题层级、简单列表、规则列距表格及按页面位置排列的图片。富文本直接使用该本机模型，Markdown 使用其便携序列化结果。素材重新绑定和新文档一次性初始化仍是保存边界。背景色、下划线、矢量图、复杂分栏/表格和公式重建可能简化；扫描页保留为图片，不进行 OCR；原解析器警告继续展示。本次不改变持久化模型、schema、旧格式转换或迁移规则。

Slate 0.4.25 已将原宿主 DOCX 补丁正式发布到 ESM/CJS 转换入口：Word 直接字体、字号、颜色、背景、段落对齐、显式关闭 marks 和单元格文本格式，以及在线标题字号、1.6 行距和 A4 默认值。任意继承样式、复杂分节和精确分页仍不在验证范围。Markdown 0.4.4 已正式包含原 KaTeX/延迟 PDF 加载修复。Doca 直接安装这两个正式包，无编辑器补丁绑定。历史补丁可从上一版 Git 源码恢复；移除它们不转换已存文档或改变协作格式。

验收：`tests/document-pdf.test.ts` 覆盖真实 WeasyPrint PDF、可选择中文、本机 PDF 重建、真实 DOCX XML/重导入以及脚本/远端图片阻断；`tests/document-pdf-access.test.ts` 覆盖只读权限、撤销和正文 checkpoint 不变。`node --import tsx scripts/qa-document-pdf.mts` 使用隔离浏览器样本，验证上下文保留、Y.Doc 零更新、图片导出后重导入、Mermaid/公式及三页长表格，视觉产物写入 `artifacts/verification/document-pdf/`。使用 Poppler 将 PDF 渲染为图片，与在线截图对照；不打开用户文档或生产数据库。

## 验收证据

剪贴板也遵守同一资源边界：包只报告文件/文本和捕获的目标位置；宿主上传图片或附件、判断本站链接并做权限查询，包再用正常编辑事务插入。异步完成时不得采用新的当前选区，也不能写入已关闭或失去编辑权限的文档。普通表格多行/制表符粘贴保留原生行为。超链接只允许安全协议；站内文档保存稳定 ID 并生成相对地址，不存域名。Excel 当前业务对象为整单元格对象，不应宣传为支持混合行内富文本；XLSX 往返可能降级为可读标签并给出警告。

使用隔离数据和实际文件，至少覆盖：基础中文/格式/表格或图形；导入后编辑并重载；导出文件重新打开或导入；不同编辑实例同步；导出前后零正文增量；只读导出与编辑禁用；损坏文件/超限/取消；素材重新绑定和无权限读取；警告可见。逐项记录通过、降级及未验收范围，构建成功不等于导入导出正确。

## 三编辑器升级 — 2026-10-17

Doca 固定安装实际 npm 包 `@smartdoca/slate` 0.4.22、`@smartdoca/slides` 0.3.0-alpha.3。Canvas 使用不可变的 `vendor/smartdoca-canvas-0.5.0-75e637df1a75.tgz`：npm 0.5.0 的库构建误删了 Slate 与纯文本内部编辑器注册模块，AidCanvas 源码已通过 sideEffects 声明修复，宿主使用重建产物。这个修复包和源码改动尚未发布 npm。

Slate 新增五页元素配色，进入图形标签编辑时全选文字。codec/Yjs/headless 字节与 0.4.20 一致，原有 DOCX 补丁原样绑定到 0.4.22。Canvas 保持 `aidcanvas-yjs` schema 1；图片和附件回调保存稳定资产 ID，传递真实进度和取消信号，并接入宿主鉴权预览，包括历史、回收站、审计只读视图。服务端校验新增富文本媒体引用属于当前文档。临时画布 presence 完整转发经过校验的相对文字位置和场景鼠标坐标，身份及颜色仍由服务端决定；支持仅鼠标消息，不复用永久评论锚点。

Slides 要求 codec revision 6。客户端与服务端统一严格协商 `eppt-yjs-v6`，文档 schema 2 / protocol 1 不变。用户明确选择**只支持新文稿**：旧 `eppt-yjs-v5` 文稿和旧客户端拒绝打开或接入，原 checkpoint、增量、epoch、历史和待提交消息标识原样保留。不增加旧 codec 读取、编码标识改写、自动转换、迁移或 SQL 结构变更。宿主接受原生文字边距与表格字段；AI 表格命令通过原生 controller 支持合并/拆分、样式、尺寸、清空、粘贴与批量删行列。单元格仍是纯文本加整格样式。

部署时服务端与 Web 必须同步更新。保留旧部署、版本锁定、补丁、锁文件与安装产物；旧程序不承诺读取新功能写入，恢复前须保留后续数据。本次没有修改用户数据库或部署。隔离验收、哈希、截图和边界见 `docs/verification/three-editor-upgrade-2026-10-17/`。
