## 原因与处理

完整页面 DOM 为 626,943 字符；最初读取工具的单次 200,011 字符截断不能作为整页证据，最终使用分段取得的完整 DOM。旧转换器对转义方括号、参考文献标签、美元价格和含美元符号的链接产生 242 条公式误报；旧收录服务遇到任意转换警告即中止。另一个问题是原图说明包含换行，生成的 Markdown 图片标记被拆成多行。

Slate 0.4.26 在正式上游修复 Markdown 转义和公式判断，保留链接与图片说明。Doca 折叠说明中的换行，接受可读转换降级；解析意外异常时保留原始 Markdown 文字及已上传图片。不支持的嵌入元素保留占位；图片读取、转换及上传阶段的图片格式验证失败也局部降级。网络、权限、配额和实际存储写入失败仍中止，不返回虚假的保存成功。

数据库结构、持久化收录格式、协议 v1、文档及协作 schema 均不变。用户明确选择不增加报告字段：问题仅在本次响应和扩展内存中展示，文档保留占位。完成请求继续幂等返回原文档，不重复创建或重放未保存的历史报告。历史失败任务仍需重新收录，不自动改写，原到期清理规则不变。
