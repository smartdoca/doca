# SVG 转换与缺图占位验收

2026-10-25：扩展 0.2.5 在新任务建立前处理图片。静态外链及内联 SVG 经清理后转为透明 PNG；不兼容、无法读取或无法转换的图片在原位置变为文字占位，保留原因及 HTTP(S) 原图链接，正文继续保存。隐藏跟踪图片不进入清单。权限、配额及存储故障仍中止提交。

用户明确同意：已保存文档、已上传图片和历史失败任务不改写；更新扩展并刷新原页面后，为旧失败页面重新发起任务。旧任务仍按原规则到期清理，不自动转换或重发。收录协议仍为 v1，资产仍为既有 PNG/JPEG/WebP/GIF 格式，无数据库结构或历史 JSON 变更；回退无需数据转换。已经暂存的任务继续保持原图片清单要求。

SVG 不挂载为页面 HTML。移除脚本及事件属性；外部引用、HTML、动画和无法安全渲染的依赖改为占位。输入传输限 32 MiB；输出最长边 4096、总像素 1600 万、PNG 不超过 4 MiB。其他图片沿用既有压缩、动图保留与大小限制。新任务预处理完成后冻结正文、图片清单和请求 ID；提交或上传故障的重试复用已有任务和已上传资产。

验证使用合成页面、独立 Chromium MV3 配置与隔离数据库，不读取或编辑用户文档、不调用模型服务。真实浏览器用 `tests/qa-browser-extension-svg.mjs` 验证无 CORS 许可的跨域 SVG、内嵌样式像素、透明背景、内联 SVG、三处缺图占位、来源链接、正文尾部、禁止 SVG 外部请求，以及提交中断后的同任务重试与零重复上传。本机额外验证 Nature 页面实际 Logo，输出 PNG 为 326 × 50，保留透明背景。复用脚本在没有该临时下载文件时使用合成 SVG。

服务端集成测试验证占位文字、来源链接及 PNG 资产能够一起保存为原生富文本文档，且不存在未解析的临时图片标记。单元测试覆盖清理、格式拒绝、尺寸限制、标签转义、中英文占位、预处理冻结，以及权限/配额错误不得被跳过。定向测试、TypeScript、正式构建及双语文档检查通过；没有发布或替换正在运行的扩展。

原始 JSON、图片、截图及执行日志位于忽略目录 `artifacts/verification/browser-extension-svg/` 和 `artifacts/verification/nature-capture-investigation/`，不作为文档附件提交。
