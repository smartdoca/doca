# 浏览器工具条控件调整

本次局部调整沿用 Doca 蓝色、浅色边框和现有图标。收录规则使用扩展共用 `DocaSelect`，不显示系统原生选择器。菜单在隔离根节点单独渲染，避免确认气泡的滚动和动画裁切；支持鼠标、键盘及先关闭菜单的 Escape 行为。

工具条在设置下方同列提供收起/展开按钮；把手以更深的六点图形、底色和边框加强识别。收起后保留把手，可继续拖动，展开时保持垂直锚点。初次出场、确认气泡、按钮反馈保留既有短动效，下拉菜单淡入、展开时图标淡入遵循减少动态效果的系统设置。没有添加装饰文案。

位置继续使用现有 `chrome.storage.local` 的 `dockPosition` 数字值。页面读取缓存后再显示工具条，避免先在默认位置闪现。没有新增缓存转换、兼容读取器或数据库字段；缓存写入失败时提示重试并保留原存储值。

可复用脚本 `tests/qa-browser-extension-dock.mjs` 已扩展覆盖：隐藏原生 select、选择第二条规则后真正收录、Escape、390px/200% 菜单边界、收起/展开不跳位、折叠拖拽、缓存保存失败、刷新及完整关闭后重启浏览器、新页面的位置恢复。测试使用合成站点和隔离浏览器存储，不调用付费模型、不写用户文档。

当前定向 111 项测试及类型检查通过，真实 Chromium MV3 初轮和补充存储失败场景通过。发布前还将执行完整回归、正式构建及三轮最终浏览器验证，正式结果记入发布回执。原始日志、截图和 JSON 位于忽略目录 `artifacts/verification/browser-extension-controls/`，不提交原始执行输出。本轮为局部控件调整，由主 Agent 在 100%、窄屏及 200% 看图自检，未另做独立评审。
