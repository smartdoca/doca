# 收录方案位置树验收

保存位置沿用文档移动弹窗的树结构、图标、层级及选中样式，在现有收录方案弹窗内选择个人文档、知识库根目录或文档下方。知识库列表使用已有资源接口的知识库筛选，单独分页；展开库时通过既有目录接口读取完整层级。没有修改接口或方案持久化格式，没有数据库升级或历史数据转换。

目录构造共享同一实现，移动仍要求管理权限，收录创建使用既有编辑权限。只读上级仍显示并允许展开，可编辑子节点可选；无写入权限的库和知识册生成目录不作为收录目的地。已有选择失效时明确提示并阻止保存，不改成个人文档。加载失败提供重试，保存失败保留输入和选择。只在恢复方案时自动滚动定位，手动选择不会被滚动带走。

15 项定向测试覆盖树排序、层级、不同操作权限、个人文档、库根、深层位置、独立分页、恢复超出首页的知识库、失败保留及切换追加方式。真实 Chromium 已在隔离 SQLite 和浏览器存储中通过初轮：创建 102 个知识库、105 个最近文档及三级目录，确认旧混合首页没有知识库，再通过实际设置页保存三种位置，刷新恢复、失败重试，并提交网页收录，核对新文档的实际知识库及父文档 ID。

100%、390px 和原生 200% 截图已由主 Agent 看图自检。本次为局部选择器调整，复用既有移动样式，未另行独立评审。树展开、行选中与弹窗沿用既有控件动效，不添加装饰说明。没有删除对象名称、层级或主操作，创建方式不再展示不适用的文档搜索框。

完整回归 3365 项通过、11 项按配置跳过，最终正式构建及连续三轮真实浏览器验收通过，实际收录的知识库与父文档 ID 均匹配所选目录。公开制品、摘要及流水线见[发布回执](release-0.2.15.md)。日志、截图、浏览器配置及 JSON 保存在忽略目录 `artifacts/verification/clipper-destination-tree/`，不提交原始执行输出。没有使用用户文档或付费模型。
