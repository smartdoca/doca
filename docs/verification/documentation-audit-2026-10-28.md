## 新增持续检查

`pnpm docs:check` 现在扫描 Git 跟踪或未忽略的仓库 Markdown，排除作为测试输入的 `tests/fixtures/`，检查 Markdown、HTML、引用式链接和本仓库 main 链接的目标、标题。公开站点另按 Docsify 规则检查锚点及中英文入口，并比对当前发行入口、编辑器版本矩阵、完整 Schema 字段及五份 skill 引用。

`pnpm test:docs` 使用隔离夹具验证可移植 skill 链接、HTML/引用式链接、忽略代码块、编码路径与越界、标题锚点、Git 忽略规则和继承/交叉类型的字段清单。文档 CI 增加检查器测试，并覆盖全仓库 Markdown、skill、检查脚本及数据库类型的变更。

生成日志、浏览器截图和临时审查脚本保存在 `artifacts/verification/documentation-audit-2026-10-28/`，不提交原始执行输出。
