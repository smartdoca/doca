# Annual Reviews 长网页收录验收

日期：2026-10-26。宿主 0.2.21，浏览器扩展 0.2.8，正式 npm `@smartdoca/slate 0.4.26`。

## 原因与处理

[实际页面](https://www.annualreviews.org/content/journals/10.1146/annurev-pharmtox-052120-084449)的完整 DOM 有 1,034,822 个字符。扩展 0.2.7 生成 420,355 字节 Markdown，12 张图片上传后，格式化模型超过既有 768 KiB 新文档导入上限；Chrome 实际收录复现 HTTP 413 和“转换后的文档不能超过768KB”。CSS 隐藏的文章副本、参考文献面板和分享菜单也被重复提取。

扩展 0.2.8 在整页提取前根据原页面的计算样式排除 `display:none` 子树，保留页面下方内容及可见 SVG 必需的样式和定义。服务端在格式转换后检查完整原生文档大小；若超限，则将完整原始 Markdown 分为每块最多 8,192 个 Unicode 码点的文字块，并保留原网页标题和已上传图片，返回本次格式降级提示。意外解析异常沿用相同的完整内容保留方式。不截断原文，不放宽既有导入上限、权限、配额或存储检查。

## 实际 Chrome 验收

用户重新加载并确认扩展版本 0.2.8 后，在原网页上点击真实浮动工具条的“收录当前页面”和“确认收录”，保存到隔离的 SQLite / 本地文件存储实例。没有修改生产数据库或既有文档。

插件显示“已保存到 Doca”，并列出一项当前图片处理失败：`ar-logo-1479872034357.svg` 格式不支持或图片内容无效。文档保留“图片未保存：Annual Reviews Icon”占位及来源链接。此问题没有阻断保存。

通过实际“打开文档”链接读取新文档 `09414388-0f92-46a6-a1ec-55c86568fbe8`。标题为原页面标题，原生模型有 1,525 个内容块、568,703 字节；本次过滤隐藏重复内容后可直接保存格式化内容，没有触发整篇纯文本降级。

打开及刷新后均核对到 139,155 个 DOM 文本字符，BACKGROUND、正文末句“the future is brighter for these diseases than ever before.”及 Literature Cited 均存在。9 张保存图片全部从 Doca 素材地址正常加载，包括两张正文 GIF（500×312、500×435）。正文图和说明已通过可见页面检查。持久化原生模型 SHA-256 为 `03880dff3e285840fb56a34885e4606bbf5d397b400e6dcabd781721da30d175`，无后续编辑更新。

验收后扩展通过设置界面恢复到原 `https://doca.heyphp.com` 站点和张思文账户，界面显示“已连接”。这是隔离后端的真实浏览器收录验收；生产服务需更新到 0.2.21，并使用扩展 0.2.8 才能获得新行为。
