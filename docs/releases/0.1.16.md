# Doca 0.1.16

[简体中文](0.1.16.zh-CN.md)

Knowledge-book workflow settings now use the graph as the single node editing entry point.

## Changes

- Remove the duplicate node editor cards beneath the workflow graph. Click a graph node to edit its name, rules, sources, acceptance criteria, weights and inputs in the existing drawer, then save the configuration.
- Left-align the icons, names and descriptions in the node palette so every row starts at the same position.

## Deployment

This patch changes the Web interface only. Database baseline `doca-2026-10-09-history-storage-v1`, configuration formats, permissions and SDK 0.1.10 remain unchanged. Existing 0.1.15 deployments can change the application image to 0.1.16 with their original data and configuration. Earlier deployments must follow the existing [0.1.15 release requirements](0.1.15.md).

## Validation

TypeScript, Web production build, 45 knowledge-book tests and 53 bilingual documentation pages passed. An isolated interface preview verified direct graph-node editing, save-button activation after edits and consistent left alignment in the palette. No user documents were edited during verification.

## Distribution

- GitHub tag `v0.1.16` with Web assets.
- Docker `docker.io/smartdoca/doca:0.1.16` and `latest`, Linux amd64 and arm64.
