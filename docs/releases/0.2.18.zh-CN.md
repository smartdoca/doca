# Doca 0.2.18 — SVG 收录与评论共享滚动

[English](0.2.18.md)

浏览器扩展 **0.2.5** 将静态外链和内联 SVG 转为保留透明背景的 PNG。不兼容、无法读取或转换失败的图片，在原位置写入占位说明、原因及原始 HTTP(S) 来源链接，正文和其他图片继续保存；排除隐藏跟踪图片。权限、配额和存储故障仍中止保存；已暂存任务在重试时保持正文、图片清单和请求 ID 不变。

富文本评论和正文在桌面与紧凑布局中使用同一个纵向滚动区域。在评论上滚动时推动整篇文档，评论卡片随正文锚点对齐移动。回复草稿、评论导航和较长回复线程继续可用，不再依赖独立评论滚动条，也不因空闲布局更新写入文档内容。

服务端与 Web 一起更新，再下载并重新加载扩展 **0.2.5**、刷新原网页。历史失败页面需重新发起收录。用户已同意保留历史任务、已保存文档和已上传图片，不自动转换或重新发送；旧任务继续按原到期规则和图片清单要求处理。收录协议 v1、位图资产格式、数据库结构、评论锚点以及文档和队列格式不变，回退无需数据转换。保留数据库、文件卷和原凭据主密钥，继续遵循[数据库升级约定](../database-schema-evolution.zh-CN.md)和[浏览器队列约定](../browser-assistant.zh-CN.md)。

SVG 在本地光栅化前清除脚本及事件属性；外部依赖、内嵌 HTML、动画和无法安全渲染的内容改为占位。SVG 输入传输限 32 MiB，PNG 输出不超过 4 MiB、最长边 4096、总像素 1600 万。其他位图沿用原压缩及动图限制。详见[收录验收](../verification/browser-extension-svg-2026-10-25.md)和[评论滚动验收](../verification/rich-comment-scroll-2026-10-25.md)。
