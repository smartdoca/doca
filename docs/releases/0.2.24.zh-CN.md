# Doca 0.2.24 — 系统 Logo 与表格评论定位

[English](0.2.24.md)

管理员可在 **站点与服务 → 站点信息 → 系统 Logo** 上传 PNG、JPEG 或 WebP 图片，预览后保存，或恢复默认图标。服务端验证不超过 5 MB、1600 万像素的非动画图片，移除源图片元数据，生成每边不超过 256 像素的 PNG。保存后用于工作台导航、登录页及非文档页面的浏览器图标；文档标签页保留现有格式/标题图标。保存失败会保留已选图片供重试，保存 Logo 不会丢弃尚未保存的站点名称输入。

已确认的可空 `settings.site_logo` 字段通过现有最新 DDL 对比机制新增，兼容代际不变。历史 NULL 沿用默认图标。保留现有设置、正文、权限和文档启动缓存格式，不新增 `account_settings` 品牌配置，也不转换历史数据。写入受管理员权限、同源检查、站点设置版本校验保护，修改与安全审计同事务提交；未知或损坏的 Logo 配置保留并拒绝处理。

更新前备份数据库、文件卷和部署配置，并同步更新服务端与 Web。旧程序现有的结构审查会拒绝新增字段；应保留后续数据，另行评审恢复，不得删列或用旧备份覆盖后续写入。发行制品为 GitHub 附件与 Docker Hub 原生 Linux amd64/arm64 镜像，发布制品不会升级正在运行的站点。浏览器扩展保持 0.2.10。

表格评论定位按冻结区域的实际像素尺寸滚动，覆盖隐藏行列和不同行高列宽，保留单元格选区、文档字节和协作状态。见 [Logo 验证](../verification/site-logo-2026-10-28.md) 和 [表格评论验证](../verification/sheet-comment-freeze-2026-10-28.md)。
