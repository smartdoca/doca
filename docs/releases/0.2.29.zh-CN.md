# Doca 0.2.29 — AI 会话历史与删除修复

[English](0.2.29.md)

新 AI 任务会在文件校验、模型初始化和附件识别之前，保存原始提问及本人附件信息。即使初始化失败，重新打开会话或刷新后仍可看到提问、附件与任务失败原因。恢复执行时保留已经保存的消息与上下文。

消息尚未到达时，欢迎页不再出现在排队或运行中的任务进度下方。加载已有会话时不显示欢迎页，开始新对话后恢复欢迎页；渲染缓存包含所选会话 ID。

删除失败原因会在确认弹窗内显示，并支持重试。有活动任务时，弹窗提供明确的“停止任务”入口，之后需再次确认删除。服务端继续拒绝删除排队、运行或待审批中的会话，包括打开弹窗后任务状态才发生变化的情况。停止任务不会自动删除会话，提示提供中英文。

本版不改变数据库结构或存储格式，不恢复历史缺失消息，也不重建或回写已有缺失记录。既有历史消息读取、重试缺省值和会话文件清理规则保持原样。更新时保留数据库、附件、配置及主密钥，服务端与 Web 一起更新；仍需遵守 [0.2.28 升级要求](0.2.28.zh-CN.md)。范围与证据见[验证记录](../verification/ai-session-history-2026-10-31.md)。

发布目标为 GitHub 附件和 Docker Hub 原生 Linux amd64/arm64 镜像。全新安装可使用 `doca-compose-v0.2.29.yaml`；已有部署保留原项目身份与持久卷。发布不等于部署运行中的网站，浏览器扩展版本仍为 0.2.11。
