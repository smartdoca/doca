# Doca 0.1.8

[中文](0.1.8.zh-CN.md)

## Changes

- Add an independent sidebar More dropdown for navigation (`web.leftMore`) and optional global plugin commands/views (`global.leftMore`). Existing `web.more` and `global.more` remain the top-right menu.
- Fix the empty More popup caused by nested absolute positioning. The top-right menu renders navigation and plugin action entries as icons, with names shown below on hover.
- Add bottom hover labels to top-right navigation, More, language and account controls.
- Distinguish both More positions in navigation settings and show their actual menu styles in previews. Preview menus do not mount executable plugin extensions.
- Preserve names in the sidebar dropdown when the sidebar is compact. Hide each More entry when its own filtered navigation and plugin contributions are empty. Support outside-click, Escape and route-change closing; plugin dialogs remain open after their trigger menu closes.

## Configuration and plugin integration

The two new positions are optional and must be explicitly declared by plugins. Built-in user navigation can be configured in either position. Existing configurations are not migrated and old plugins do not acquire the new positions automatically. Existing overflow and deduplication rules remain, with explicit placements in both More menus allowed.

No database migration or automatic data conversion is introduced. Before rolling back to a host that does not support `web.leftMore`, remove and publish those placements and roll back plugin declarations that use the new positions. The older host keeps strict validation.

New SDK slot types are included in the GitHub source. This release publishes the host on GitHub and Docker Hub; the public npm SDK remains 0.1.5 and does not include these source additions.

## Distribution

GitHub tag: `v0.1.8`. Docker images: `docker.io/smartdoca/doca:0.1.8` and `docker.io/smartdoca/doca:latest`, for Linux amd64 and arm64.

The GitHub Release includes web assets and a SHA-256 checksum file. Extract and publish its `assets` directory unchanged when using `DOCA_ASSET_BASE`.
