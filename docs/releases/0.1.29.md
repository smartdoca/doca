# Doca 0.1.29

[简体中文](0.1.29.zh-CN.md)

Updates the rich-text editor to the published `@smartdoca/slate` 0.4.20 artifact. Mind maps gain a full workspace with an outline, topic navigation and reordering, branch editing, search, themes, map structures, typography, SVG export and unsaved-change protection. The included 0.4.19 fixes improve diagram selection, property draft commits, media previews, shape connector ports and preset navigation.

AI editing guidance now describes the native mind-map settings and preserves the full tree, existing IDs and unspecified fields. The existing DOCX style patch is applied unchanged to 0.4.20. Other editor packages and public workspace SDK versions are unchanged; no npm publication is required.

## Upgrade and rollback

From 0.1.28, stop instances, retain databases, files, configuration and the master key, then deploy matching host and Web builds. Public entrypoints and dependencies are unchanged; codec, Yjs, headless and conversion runtime bytes match 0.4.18. Rich-text schema 3, epochs, checkpoints and pending update identities are unchanged. No database structure change, migration or historical field backfill is introduced.

The user approved the new native mind-map display defaults for existing documents. An old preview is regenerated in view state without rewriting stored content. Opening and closing the workspace without saving creates no content commit. Explicit saving commits the native draft/settings and version-6 preview through the existing collaboration outbox and durable ACK.

Retain the 0.1.28 image, package artifact, dependency pin, patch and lockfile for rollback. Older editors may ignore new settings/styles or display different defaults. Preserve later writes during recovery; restoring a pre-upgrade backup discards subsequent edits. Earlier installations still require the [0.1.26 plugin database upgrade procedure](0.1.26.md#required-upgrade-from-0125).
