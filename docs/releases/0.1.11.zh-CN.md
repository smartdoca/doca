# Doca 0.1.11

[English](0.1.11.md)

## 变更

- 原有 `image_generate` 工具增加可选参考图 ID。模型自行选择当前会话本轮或历史上传图片、已生成图片，用户无需切换模式。GPT Image 和兼容服务使用 `/images/edits`；Seedream 4.x/5.x 在 `/images/generations` 中传参考图。不支持图生图时明确失败，不自动改为文生图重试。
- 调用厂商前校验参考图归属、会话、删除状态、大小、媒体类型及实际解码内容；多图保持指定顺序，生成结果保存前再次复核权限。
- Meilisearch 设置、账户联系方式、账户恢复和默认聊天模型设置中共五处可见原生选择框改用统一下拉框。必填校验会聚焦并展开下拉框，Meilisearch 控件填满可用宽度。
- 浏览器附件上传改为最多两个请求并发排队。AI 附件显示本地图片预览和上传进度，移除附件或关闭输入组件时取消上传；服务端错误保留状态码和诊断信息。
- 补充 Docker 本地存储路径和上传 `EACCES` 排障说明，区分开发 `.env` 路径与容器 `/data/storage`，修复时保留持久数据。
- 收录 0.1.10 之后新增的中英文 Docsify 文档站。

## 部署与数据

本版沿用 0.1.10 的 `doca-2026-10-03-credentials-v2` 数据库基线、插件契约及部署配置。从 0.1.10 升级无需数据库迁移或存储转换。替换应用镜像前备份数据库和存储，保留旧镜像及配置用于回退。

从 0.1.9 或更早版本升级仍适用 [0.1.10 的要求](0.1.10.zh-CN.md#不兼容部署要求)：保留原部署和数据，使用新空数据库及独立存储。本版不新增自动迁移、转换或数据重置。

不新增 AI 工具、SDK 包版本或附件/生成结果持久格式。现有图像模型配置、尺寸规则、返回格式规则和用量记账保留。真实图生图能力取决于所配置的服务和模型。
