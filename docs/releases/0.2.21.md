# Doca 0.2.21 — Save long webpage conversions

[简体中文](0.2.21.zh-CN.md)

Browser extension **0.2.8** excludes CSS-hidden article copies, reference panels and menus from full-page capture. Below-the-fold content remains included, and visible SVG images retain their styles and definitions.

When formatting expands an accepted capture beyond the existing **768 KiB** new-document import limit, the server saves the complete original Markdown as bounded plain-text blocks, preserves the page title and uploaded images, and returns a visible format-degradation notice. It does not truncate the article or repeatedly retry an oversized formatted model. The existing import limit, capture source limits, asset authorization, quota checks and storage failures remain enforced. Appending to existing documents keeps its existing size policy.

No database structure, document schema, protocol version, frozen task format or report storage changes. Existing documents and tasks are not rewritten. Start a new capture to apply the new extraction rules; completed requests continue returning the same saved document. Update the server to **0.2.21** and download/reload extension **0.2.8**. Preserve existing data and later writes during rollback; no data conversion is required.

Regression coverage verifies complete source and image preservation, Unicode text blocks, the original title, CSS-hidden duplicates, and visible SVG styles using isolated documents.
