# Doca 0.1.7

## Changes

- Expand optional plugin commands, views and placements across home cards, document menus and panels, library and file menus, and global More navigation. Empty entry points remain hidden.
- Add public native document snapshots, library traversal and a shared policy-aware user directory. Built-in modules and plugins contribute authorized user relationships to the same directory.
- Add template and material provider/consumer services, public clients and reusable pickers. Providers are optional; the host installs none by default. The old template UI/API are retired under the agreed plan, while the old table and data remain untouched.
- Search registered content sources and carry search queries into document search. Use the spreadsheet model for spreadsheet find and preserve native find/replace entry points.
- Fix AI chat initialization with namespaced plugin skill IDs and preserve Chinese IME composition in document search.

## Public npm packages

- `@smartdoca/plugin-sdk@0.1.5`
- `@smartdoca/plugin-contracts@0.1.4`
- `@smartdoca/web-plugin-registry@0.1.2`

The existing file, search and knowledge capability packages remain at `0.1.1`. This release adds optional registrations and public methods; existing page-only plugins require no new registration. No new data migration or automatic conversion is introduced.

## Distribution

GitHub tag: `v0.1.7`. Docker image: `docker.io/smartdoca/doca:0.1.7`, with Linux amd64 and arm64 builds. The GitHub Release includes web assets; publish its `assets` directory unchanged when using `DOCA_ASSET_BASE`.

The release is tested against isolated fixtures and container data. Mobile source changes are included; native store binaries and device acceptance are outside this release.
