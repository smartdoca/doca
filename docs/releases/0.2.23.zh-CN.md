# Doca 0.2.23 — 编辑器评论与资源交接

[English](0.2.23.md)

Doca 的五种编辑器均使用 npm 正式发布版本。本次接入表格、幻灯片原生评论背景，以及画布表格连接点交互。打开评论侧栏或通过评论链接定位时不预先添加背景。点击某条评论后，仅为该评论对应的内容添加背景；切换评论时替换，点击其他位置、解决评论或关闭侧栏时清除，重新打开不恢复之前的高亮。高亮仅为视图状态，不修改单元格样式、图形填充、Yjs 事务或永久锚点。编辑表格单元格时隐藏连接点；非编辑悬停或选中整表时显示。

评论图片使用当前页大图预览，支持缩放、复制与下载；操作文件来源窗口时保留当前评论。未登录打开私有文档直接进入登录，成功后保留原文档与评论定位参数。文档树缩进减小。部署说明统一拉取 main，以该分支 Compose 指定的镜像为准。AI 任务运行时保留消息气泡的完整布局；尚无详细信息的那条 AI 工具失败仍需对应会话和错误原因，本版本不宣称已解决。

管理员可对已停用账号勾选资源与保留授权，通过预览与确认交接给有效接收人。既有权限冲突与接收人限制阻止提交；所有权、授权和安全审计事务提交。原内容、历史作者、上传人和存储对象保留。见[管理员资源交接](../admin-resource-handover.zh-CN.md)。

没有数据库结构、文档 schema/codec、永久锚点格式、epoch、检查点或历史数据转换变更。既有兼容读取与升级门禁保持原规则。服务端与网页应一起更新。回退二进制时保留数据库、对象、配置和后续编辑；已确认的资源交接属于业务变更，不会因二进制回退自动撤销。

浏览器扩展保持 0.2.10。

验证记录：[五种格式评论背景](../verification/editor-comments-2026-10-28.md)。
