# Doca 0.2.17 — Comments and browser assistant

[简体中文](0.2.17.zh-CN.md)

This release brings the browser assistant, comment controls, and documentation updates together.

Replies use tighter spacing. Deleting a comment first opens a confirmation bubble; canceling sends no deletion request. All five editor comment sidebars have a Resolved comments icon. Its dialog lists resolved threads and replies, lets authors and managers mark a thread unresolved, and preserves the list when restoration fails. Existing permissions, optimistic comment versions, anchors and editor persistence remain authoritative.

The browser assistant validates a remembered session against the current capture rule before restoring it, avoiding the misleading access-change error after a rule edit. Original sessions and pending messages remain. New attached webpages appear as deduplicated source links in operated resources. The first accepted message gives a new browser conversation a page-first title with its request and hostname; an accessible browser icon replaces repeated source text. Historical and manually named conversations are preserved. Rich-text navigation and AI controls remain at the far right with comments expanded.

README and user guides now explain browser extension setup and MCP services. The documentation index, capability versions, existing local replica/queue support, comment recovery and multi-replica notification requirements have been corrected against current source.

Update the server and Web together. Download and reload browser extension **0.2.4** when upgrading from 0.2.15 or earlier. Database structure, authentication/capture protocols, comment/anchor formats and persisted queues remain unchanged. No historical data is converted, backfilled or deleted. Preserve database/file volumes and the credential master key, following the existing [database upgrade contract](../database-schema-evolution.md) and [browser queue rules](../browser-assistant.md).

The earlier 0.2.16 GitHub artifacts were generated before this combined scope was requested. Its unfinished image publication was stopped; use **0.2.17** for the complete GitHub and Docker Hub release. Published source tags are not moved.
