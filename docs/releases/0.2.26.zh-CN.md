# Doca 0.2.26 — 搜索相关性与表格编辑修复

[English](0.2.26.md)

平台和 AI 助手搜索在计数、分页前，使用当前已授权标题和完整正文过滤候选。多词主题不能仅因共享 DOCA 等品牌词而命中；没有相关内容时返回空列表。文件搜索成功返回空结果时，不再重新列出候选。此过滤偏重精确度，没有共享实质词的同义描述可能被遗漏；既有 AI 分数设置和权限检查继续执行。

正式 npm 依赖 **@smartdoca/sheet 0.2.15** 修复“换行”“合并”文字点击，以及不同行高、列宽的冻结区遮挡正在编辑的单元格。宿主回调及公开接口签名不变；声明差异仅为生成文件名哈希与联合类型顺序。model、Yjs、preferences、XLSX 运行时与 0.2.14 字节一致，不新增宿主滚动补丁、props、schema 或数据转换。

根据本次明确批准的规则，同一知识库内拖拽目录时保留回收站后代，仍须有整棵子树的管理权限。后代内容、删除状态、父子身份及授权记录保留；拖拽失败提示不会再被列表刷新清除。

本次不增加数据库结构或持久化格式变更。已有历史读取和获批默认值沿用原路径。保留上一部署与依赖锁文件用于包回退，并保留升级后的全部内容。从 0.2.24 之前升级还须遵守 [0.2.24 发行要求](0.2.24.zh-CN.md)。验收见[问题修复记录](../verification/issue-record-host-2026-10-29.md)。

发布目标为 GitHub 发行附件与 Docker Hub 的原生 Linux amd64/arm64 镜像；发布不代表已更新运行中的 Doca 网站。
