# Doca 0.1.29

[English](0.1.29.md)

富文本编辑器升级到已发布的 `@smartdoca/slate` 0.4.20。思维导图新增完整工作区，支持大纲、主题导航与排序、分支编辑、搜索、配色、结构、字体样式、SVG 导出及未保存修改保护。同时包含 0.4.19 的图形选择、属性草稿提交、媒体预览、形状连接点和预设翻页修复。

AI 编辑说明补充原生思维导图设置，要求保留完整树、已有 ID 和未指定字段。原 DOCX 样式补丁内容不变，绑定到 0.4.20。其他编辑器包及公开工作区 SDK 版本不变，无需发布 npm。

## 升级与回退

从 0.1.28 升级时停止实例，保留数据库、文件、配置和主密钥，成套更新宿主与 Web。公开入口及依赖不变；codec、Yjs、headless、conversion 运行时代码与 0.4.18 字节相同。富文本 schema 3、epoch、checkpoint 和待确认更新身份不变，没有数据库结构修改、迁移或历史字段补写。

用户已同意新版原生默认显示作用于已有思维导图。旧预览只在视图中重新生成，不回写存储内容；打开工作区后不保存关闭不会产生内容提交。只有明确保存，才通过现有协作 outbox 与落库 ACK 提交原生草稿／设置和版本 6 预览。

保留 0.1.28 镜像、包制品、版本锁定、补丁及 lockfile 供回退。旧编辑器可能忽略新设置／样式或显示不同默认值。恢复时保留后续写入；恢复升级前备份会丢失其后的编辑。更早部署仍须遵守 [0.1.26 的插件库升级要求](0.1.26.zh-CN.md#从-0125-升级的必要步骤)。
