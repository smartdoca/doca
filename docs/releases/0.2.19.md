# Doca 0.2.19 — Capture linked images from Nature pages

[简体中文](0.2.19.zh-CN.md)

Browser extension **0.2.6** fixes page capture when an image or inline SVG is wrapped in a hyperlink. It emits the image and a separate readable target link instead of nested image/link Markdown. Nature's publisher and sponsor logos previously triggered conversion warnings that stopped the entire capture. Images, links, article text and references now save together; the server continues to reject unexpected conversion warnings.

The reported live Nature page was captured through Chrome's actual floating toolbar, saved to Doca, opened and reloaded. All eight images loaded from Doca assets, including both SVG logos converted to PNG; four image target links, the final article paragraphs and references were retained. See the [acceptance record](../verification/nature-capture-2026-10-26.md).

Download/reload extension **0.2.6**, refresh the source page and start a new capture for a failed page. The approved historical-task policy remains: saved documents, uploaded images and frozen failed tasks are not rewritten or resubmitted automatically; old tasks retain their existing expiry. This fix changes only new page extraction and does not change protocol v1, database structure, stored document formats, permissions or editor dependencies. Rollback requires no data conversion; preserve all existing data and subsequent writes. The extension fix also works with the 0.2.18 server.
