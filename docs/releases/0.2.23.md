# Doca 0.2.23 — Editor comments and resource handover

[简体中文](0.2.23.zh-CN.md)

Doca now uses the official npm releases of all five editors. This release integrates native spreadsheet and slide comment backgrounds and the Canvas table connection-point interaction. Opening the sidebar or following a comment link does not paint a background. Clicking a comment highlights only its associated content; clicking another comment replaces it, and clicking elsewhere, resolving the thread or closing the sidebar clears it. Reopening does not restore a previous highlight. Highlighting is view state and never writes cell styles, shape fills, Yjs transactions or permanent anchors. Table cell editing keeps connection points hidden; non-editing hover or whole-table selection exposes them.

Comment images open in the current-page image viewer, with zoom, copy and download. The comment composer retains its thread while interacting with file-source dialogs. Signed-out private-document links open sign-in directly, and successful sign-in restores the original document and comment target. The document tree uses a smaller indent. Deployment instructions consistently clone main and use its Compose image. AI bubbles retain full layout while a task is running; the specific unreported AI tool failure still needs its conversation/error details and is not claimed resolved.

Administrators can hand over selected resources and retained grants from a disabled account to an active recipient through a preview and confirmation flow. Existing conflicts and recipient restrictions block confirmation. Ownership/grant changes and security audit commit atomically; original content, history authors, uploaders and stored objects remain. See [administrator resource handover](../admin-resource-handover.md).

No database structure, document schema/codec, permanent anchor format, epoch, checkpoint or historical-data conversion changes. Existing compatibility readers and upgrade gates retain their established behavior. Update server and Web together. Preserve databases, objects, configuration and later edits when reverting binaries; a confirmed resource handover is a business change and is not automatically undone by a binary rollback.

The browser extension remains 0.2.10.

Verification: [five-format comment backgrounds](../verification/editor-comments-2026-10-28.md).
