# Doca 0.2.25 — Open Doca from the browser toolbar

[简体中文](0.2.25.zh-CN.md)

Browser extension **0.2.11** adds **Open Doca website** above Settings in the floating toolbar. Clicking it opens the currently configured Doca site in a new tab, including when signed out. A missing or invalid site configuration opens the extension settings. The action reads the validated site address in the extension worker, with Chinese/English labels and keyboard activation.

Update Doca, download `doca-browser-assistant-0.2.11.zip` from **Browser assistant**, reload the extension in Chrome / Edge and refresh open webpages. Updating the server alone does not update an installed extension. No permissions, server APIs, database structures or persisted formats change in this release. Pending captures, conversations and connection settings retain their existing behavior. See [toolbar acceptance](../verification/browser-extension-open-site-2026-10-29.md).

This patch includes the [0.2.24 system Logo and frozen-pane comment navigation changes](0.2.24.md). Upgrades from earlier releases must also follow that release's approved database requirements. GitHub assets and native Linux amd64/arm64 Docker Hub images are the published artifacts; publication does not deploy a running site.
