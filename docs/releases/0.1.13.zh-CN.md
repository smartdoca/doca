# Doca 0.1.13

[English](0.1.13.md)

## 改动

- 图片工具区分文生图、参考图生成和底图编辑，按明确的模型规格选择火山、千问、OpenAI 兼容及可选本机协议适配器，可分别设置工具模型。
- 图片批次保存完整输入清单、正式要求、逐页计划、候选、用量与交付文件链接。大任务按文档和页面分片执行；返修有累计次数限制和候选选择机制，不无限重新生图。
- 验收依据用户的实际要求，普通任务允许自然融合与插画风格；只有明确要求像素精度时才进行对应检查。严重角色错误、拼接及畸形仍不能冒充合格交付。
- AI 上传入口简化，提供全局和逐用户上传限制、可浏览的文件夹引用、持久附件读取及按账号/会话隔离的浏览器草稿。包含 0.1.12 的同名目录隔离与真实文件 ID 修复。
- PDF 逐页读取文字及完整视觉页面；DOCX、PPTX、XLSX 结合 LibreOffice 页面渲染和源结构读取。Docker 包含 LibreOffice、带沙箱的 Chromium 及中文字体。
- 新增知识册：多人共建来源与编排流程、网页搜索及授权插件来源、验收项与人工待办、只读 Markdown 文档树、版本与真实执行溯源。个人 AI 助手与人工页面调用相同命令和权限。
- 移除旧知识库整理与问答机器人，保留可编辑文档库、来源订阅、索引及通用搜索。
- 显式部署服务地址支持 HTTP/HTTPS，包含内网 S3/RustFS、站点、资源/CDN、身份服务、AI 连接和插件服务。浏览器 UUID、SHA-256 和文本复制适配只补充缺失能力，不转换已有 ID、摘要或文档；任意网页请求仍保留 SSRF 检查。
- 登录有效期通过环境变量配置：Web 的 `DOCA_SESSION_TTL_SECONDS` 默认 86400 秒（24 小时），手机的 `DOCA_MOBILE_SESSION_TTL_SECONDS` 默认 15552000 秒。已有 Web 会话记录不批量重写。

## 部署与数据

**本版数据库基线为 `doca-2026-10-08-knowledge-books-v2`。0.1.12 及更早版本的数据库在结构变更前被拒绝，不能直接用本版镜像启动旧库。**

保留原部署、数据库、文件和配置；新版本使用另一个空数据库与独立存储。不提供自动迁移、转换、重置或旧整理接口适配。回滚使用原代码及未改动的旧数据库，新版本产生的记录和文件也应保留。不得为启动新版删除已有数据库。

解析缓存严格使用 `parserVersion:4`，旧缓存拒绝读取并保留。知识册来源组只接受 `version:1` 的完整绑定清单，不自动转换旧单项来源。旧图片模型按已批准的规格默认规则读取；新增 Wan/MFLUX 规格必须明确配置。图片批次的显式升级保留原范围、历史任务、候选、费用与累计次数；回滚旧代码可能不能继续新版批次，恢复本版后才可继续。

单页累计生成次数通过 `DOCA_AI_IMAGE_MAX_ATTEMPTS_PER_PAGE` 配置，默认 5，支持正安全整数，重启后生效。它限制生成请求，不表示所有次数都会付费；本机适配器也计入次数。本版不启动、下载或打包本机图片模型和权重。

## 验证与限制

发行验证结果、镜像摘要和 Web 资源校验记录在 Release 附件。协议回归使用隔离数据库和模拟厂商响应，不替代真实图片质量验收。

**两组故事书逐页图片任务仍未完成全部合格交付，本版不宣称通过该整批验收。** 图片模型能力、人物一致性和自然融合仍取决于实际模型及输入；未通过的页面应保留失败依据。

知识册成果发布重新检查来源与贡献者权限。失权或来源不可用时限制相关成果读取，保留存储数据；管理员权限不会替代原来源授权。
