# Doca 0.2.17 — 评论管理与浏览器助手

[English](0.2.17.md)

本版本统一交付浏览器助手、评论管理和文档更新。

收紧评论回复间距；删除前显示气泡确认，取消不会发送删除请求。五种编辑器的评论栏顶部增加「已解决的评论」图标，弹框可查看已解决线程和回复，作者或管理者可恢复为未解决，失败时保留列表并提示。继续使用既有权限、评论版本、锚点和编辑器持久化规则。

浏览器助手恢复上次会话前，先按当前收录规则校验，修复规则更新后的误导性访问权限报错，原会话与待发送消息保留。新消息附加的网页进入「操作过的资源」，同一网址去重，可直接打开来源。新会话首条消息被接收时，以网页名称开头，结合请求和域名生成标题；来源文字改为带无障碍说明的浏览器图标，历史标题和手动命名保持原样。富文本评论区展开时，上下跳转和 AI 按钮仍位于最右侧。

README 和使用指南补充浏览器插件安装与 MCP 服务，校正文档首页、能力版本、本地副本与队列的已实现状态、评论恢复入口及多副本通知的配置要求。

服务端与 Web 一起更新。从 0.2.15 或更早版本升级时，请重新下载并加载浏览器扩展 **0.2.4**。数据库结构、认证与收录协议、评论与锚点格式及持久队列保持原样，不转换、回填或删除历史数据。保留数据库、文件卷与原凭据主密钥，继续遵循[数据库升级约定](../database-schema-evolution.zh-CN.md)和[浏览器队列约定](../browser-assistant.zh-CN.md)。

0.2.16 的 GitHub 制品在本次合并交付范围确定前已生成，尚未完成的镜像发布已停止。请使用 **0.2.17** 获取这次完整的 GitHub 与 Docker Hub 发布；不移动已公开的源码标签。
