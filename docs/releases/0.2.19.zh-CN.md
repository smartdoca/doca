# Doca 0.2.19 — 修复 Nature 页面图片链接收录

[English](0.2.19.md)

浏览器扩展 **0.2.6** 修复图片或内联 SVG 外层带有超链接时整页收录失败的问题。扩展分别保留图片和可点击的目标链接，不再生成转换器无法识别的嵌套图片链接 Markdown。Nature 的出版方和赞助方 Logo 此前会触发转换警告并中止整篇收录；修复后图片、链接、正文和参考文献一起保存，服务端仍拒绝意外转换警告。

已通过 Chrome 实际浮层收录用户报告的 Nature 原页面，打开并刷新保存的 Doca 文档。八张图片均从 Doca 资产加载，其中两个 SVG Logo 转为 PNG；四处图片目标链接、正文最后段落及参考文献均保留。详见[验收记录](../verification/nature-capture-2026-10-26.md)。

下载并重新加载扩展 **0.2.6**，刷新原网页后，为失败页面重新发起收录。沿用已同意的历史任务方案：已保存文档、已上传图片和已冻结的失败任务不改写、不自动重发；旧任务按原到期规则清理。本次只修改新页面提取，不改变协议 v1、数据库结构、文档格式、权限或编辑器依赖，回退无需转换数据，并须保留全部既有数据及后续写入。此扩展修复也可配合 0.2.18 服务端使用。
