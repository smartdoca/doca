# Doca 0.1.7

[English](0.1.7.md)

## 变更

- 扩展可选插件 commands、views、placements，覆盖主页卡片、文档菜单和面板、知识库与文件菜单、全局更多导航；空入口隐藏。
- 增加公开原生文档快照、知识库遍历及遵循策略的共用用户目录；内置模块与插件向同一目录贡献已授权关系。
- 增加模板与素材提供者/消费者、公开客户端和可复用选择器。提供者可选，默认不安装。按已确认方案退出旧模板界面和 API，原表及数据保持原状。
- 检索已注册内容来源，把搜索词带入文档搜索；表格查找使用表格模型并保留原生查找替换入口。
- 修复带命名空间的插件技能导致的 AI 会话初始化问题，保留文档搜索中的中文输入法组合状态。

## 公开 npm 包

- `@smartdoca/plugin-sdk@0.1.5`
- `@smartdoca/plugin-contracts@0.1.5`
- `@smartdoca/web-plugin-registry@0.1.2`

文件、搜索和知识能力包保持 `0.1.1`。本版增加可选注册和公开方法，只有页面的现有插件无需增加注册。不新增数据迁移或自动转换。

## 分发

GitHub 标签 `v0.1.7`，Docker 镜像 `docker.io/smartdoca/doca:0.1.7`，支持 Linux amd64 和 arm64。GitHub Release 包含 Web 资源；使用 `DOCA_ASSET_BASE` 时原样发布其中 `assets` 目录。

发行验证使用隔离数据和容器。包含移动端源码修改，原生商店二进制和设备验收不在本次发行范围。
