# Doca 0.2.14 — 浏览器工具条控件

[English](0.2.14.md)

浏览器扩展 **0.2.3** 将网页收录规则的系统原生选择器改为 Doca 共用下拉框，支持鼠标、键盘、点外部或 Escape 关闭。菜单独立于可滚动的确认气泡，不会被裁切；第一次按 Escape 先关闭菜单。

右侧工具条新增收起/展开按钮，拖拽把手加深并增加底色。收起后仍保留把手与展开键，可以继续上下拖动；切换展开状态保持原来的垂直位置。

工具条读取已有本机位置缓存后才显示，刷新、打开另一网页和重启浏览器均能恢复已保存的位置。缓存写入失败会明确提示重试，并保留上一次保存值。位置沿用现有缓存键和数字格式，不转换历史缓存、不增加服务端或数据库结构。

更新 Doca 后，从「浏览器助手」设置重新下载扩展，替换已解压的文件，在 Chrome / Edge 重新加载扩展 0.2.3，并刷新已打开网页。仅更新服务端不会更新旧扩展。

本次不改变数据库、编辑器 SDK、鉴权或 AI 待发送队列格式。保留原数据及浏览器存储，回退继续遵守既有队列停用约定。详见[控件验收](../verification/browser-extension-controls-2026-10-24.md)。
