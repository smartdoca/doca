# Doca 0.1.9

[English](0.1.9.md)

## 变更

- 实现宿主持有的结构化 SQL 业务库和私有二进制对象。句柄绑定插件 ID、数据版本与安装代次；业务表、普通文件和对象路径使用命名空间避免冲突。停用保留数据，卸载阻断旧句柄并清理私有数据，保留用户文件和历史发行包。
- 文件存储配置及凭据迁至 `DOCA_FILE_STORE_ID`、`DOCA_FILE_STORES_JSON`。管理员页面只读展示后端。容器默认本地 `/data/storage`，全部副本使用同一持久后端。
- 增加富文本/表格插件元素、宿主助手启动、模板/素材检索和可复用选择器。提供预构建元素和存储 SDK 示例，生产镜像默认不安装。
- 修复 Markdown 首次编辑检查点、同版本重装待重启状态、知识来源订阅即时刷新和已退出模板管理的导航入口。
- 健康、就绪、存活和 OpenAPI 响应统一报告宿主包版本。

## 不兼容部署要求

本版明确不支持旧版本。宿主基线为 `doca-2026-10-03-storage-v1`，共享插件清单 version 2，插件必须声明 `doca.storage: "host"`，SDK 范围最低版本至少 0.1.7。旧数据库、安装清单、存储配置和 SDK 范围明确拒绝，不迁移、转换或删除旧数据。

使用新空数据库及独立持久存储。保留旧部署、数据库和存储用于回退，新部署数据独立保留。业务插件针对 SDK 0.1.7 重建并声明宿主存储。多实例需共享 PostgreSQL、Redis 和文件存储。插件变化后逐个手动重启全部实例；响应只报告当前服务实例的运行选择，不代表整个集群完成。

SDK 作用域约束公开服务隔离，受信任 Node.js 插件不构成操作系统沙箱。私有对象上传后数据库提交失败可能留下无引用字节，不提供自动孤儿扫描。

## 验证

默认测试在 179 个文件中通过 1166 项，跳过 3 项环境条件测试；PostgreSQL/Redis 单独通过全部 3 项条件测试。TypeScript、Web 构建和独立 SDK JavaScript/声明消费者通过。本地浏览器使用共享 PostgreSQL、Redis 和文件存储的两个独立实例，见[详细记录](../storage-browser-acceptance.md)。

Linux amd64、arm64 镜像均通过新数据库初始化、健康启动、登录、SDK 业务库读写、私有对象往返、普通文件创建、内容来源发现、静态资源和持久状态重启；健康及 OpenAPI 版本核对为 0.1.9。

不声明真实 AI、邮箱、SSO、Webhook、S3、CDN 服务、移动设备构建、幻灯片全屏或所有编辑器菜单已完成验收。不使用生产用户数据。
