# Doca 0.2.25 — 从浏览器工具条打开 Doca

[English](0.2.25.md)

浏览器扩展 **0.2.11** 在浮动工具条的设置按钮上方增加「**打开 Doca 网站**」。点击后在新标签页打开当前配置的 Doca 站点，未登录时也可使用。未配置站点或配置无效时打开插件设置。扩展后台读取并验证站点地址，提供中英文提示及键盘操作。

更新 Doca 后，在「浏览器助手」下载 `doca-browser-assistant-0.2.11.zip`，在 Chrome / Edge 中重新加载扩展并刷新已打开的网页。仅更新服务端不会更新已安装扩展。本版不改变权限、服务端 API、数据库结构或持久化格式；待收录材料、会话和连接配置继续遵守已有规则。见[工具条验收](../verification/browser-extension-open-site-2026-10-29.md)。

此补丁包含 [0.2.24 的系统 Logo 和表格冻结区域评论定位修复](0.2.24.zh-CN.md)。从更早版本升级时，还需遵守该版已确认的数据库升级要求。发布制品包括 GitHub 附件和 Docker Hub 原生 Linux amd64/arm64 镜像；发布不等于部署运行中的站点。
