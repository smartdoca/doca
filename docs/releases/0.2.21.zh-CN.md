# Doca 0.2.21 — 长网页转换后仍可保存

[English](0.2.21.md)

浏览器扩展 **0.2.8** 在整页收录时排除 CSS 隐藏的文章副本、参考文献面板和菜单。页面下方的内容仍会收录，可见 SVG 的样式和定义仍保留。

已经满足收录源内容上限的网页，如果格式转换后超过既有的 **768 KiB** 新文档导入上限，服务端保留完整原始 Markdown，分为有界的纯文本段落保存，同时保留网页标题、已上传图片并返回可见的格式降级说明。不截断正文，也不反复重试同一份超限的格式化模型。既有导入上限、源内容上限、素材授权、配额检查及存储失败处理保持有效，追加到已有文档沿用原有大小规则。

数据库结构、文档 schema、协议版本、冻结任务格式和报告存储均不变，不改写既有文档或任务。使用新的提取规则需重新发起收录；已完成请求仍幂等返回原文档。更新服务端到 **0.2.21**，并下载、重新加载扩展 **0.2.8**。回退时保留既有数据和后续写入，无需转换数据。

回归使用隔离文档，覆盖完整原文和图片保留、Unicode 分段、原始标题、CSS 隐藏副本与可见 SVG 的样式。
