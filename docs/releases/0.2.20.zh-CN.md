# Doca 0.2.20 — 网页转换失败局部降级

[English](0.2.20.md)

浏览器扩展 **0.2.7** 和配套服务端在内容无法完整转换时继续保存页面。失败图片及不支持的嵌入内容保留占位；转换警告不再中止整篇收录。转换器意外异常时，保留原始 Markdown 文本及已上传图片。本次请求返回转换问题，扩展在保存成功及文档链接旁列出失败信息。

正式 npm 依赖 **@smartdoca/slate 0.4.26** 修复参考文献转义方括号、图片说明转义、美元价格及含美元符号的链接被误认为公式的问题。生成 Markdown 前折叠图片说明中的换行。真实公式及 HTML 降级仍会在文档中保留可见说明。

数据库、持久化收录内容、协议版本和文档结构均不变；问题清单仅用于本次响应，不新增持久化报告。响应中断后可幂等重试，已完成任务返回原文档，不重复创建，也不声称回放历史失败清单。历史失败任务重新收录，原暂存任务仍按既有规则到期。回退保留已保存文档、已上传图片及后续写入。权限、配额及存储写入失败仍明确报错。请一起更新服务端和扩展以获得新的收录行为。

详见 [Annual Reviews 验收记录](../verification/annualreviews-capture-2026-10-26.md)。

扩展新增本站版本检查和升级下载入口；Doca 下载区、按钮及 ZIP 文件名统一带版本号 `doca-browser-assistant-0.2.7.zip`。检查失败不影响收录，也不声称已是最新版。旧解压扩展仍需手动重新加载或安装一次新版，后续可收到升级提示；不自动安装或强制降级。详见[升级提示验收](../verification/browser-extension-updates-2026-10-26.md)。
