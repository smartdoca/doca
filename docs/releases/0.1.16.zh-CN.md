# Doca 0.1.16

[English](0.1.16.md)

知识册流程设置统一从流程图节点进入编辑。

## 改动

- 移除流程图下方重复的节点编辑卡片。直接点击流程图节点，在现有抽屉中修改名称、规则、来源、验收要求、权重和输入节点，再保存配置。
- 左侧节点面板的图标、名称和说明统一左对齐，每一行从相同位置开始。

## 部署

本次补丁只修改 Web 界面。数据库基线 `doca-2026-10-09-history-storage-v1`、配置格式、权限及 SDK 0.1.10 均保持不变。已有 0.1.15 部署可保留原数据和配置，更换应用镜像为 0.1.16。更早版本仍须按现有 [0.1.15 发行要求](0.1.15.zh-CN.md)操作。

## 验证

TypeScript、Web 生产构建、45 个知识册测试及 53 页双语文档检查通过。隔离界面预览验证了直接点击流程图节点编辑、修改后保存按钮启用，以及节点面板统一左对齐。验证期间未编辑用户文档。

## 发布

- GitHub 标签 `v0.1.16`，附 Web 资源。
- Docker `docker.io/smartdoca/doca:0.1.16` 与 `latest`，Linux amd64、arm64。
