# Doca 0.2.15 — 收录位置树

[English](0.2.15.md)

浏览器助手的收录方案改用与文档移动相同的树形位置选择框。新收录内容可保存到「个人文档」、某个知识库根目录，或具体文档下方。知识库单独加载和分页，修复最近文档占满首页时，保存位置只剩「个人文档」的问题。

再次编辑方案，会展开原知识库及上级目录，并滚动定位到已选位置。只读文档作为不可选的上级节点保留。目录加载失败时可明确重试，原位置不会被重置；保存失败保留当前选择。创建目录与移动文档仍使用各自的权限要求。超大知识库遵守现有目录接口的 10,000 节点上限，截断时显示提示。

本次修改 Doca 设置页。更新 Doca 并刷新「浏览器助手」设置即可，扩展仍为 0.2.3。方案字段、接口格式、数据库结构和已有内容均不变，不自动转换或改写历史方案。

详见[位置选择验收](../verification/clipper-destination-tree-2026-10-24.md)。
