# Doca 0.2.24 — System Logo and spreadsheet comment navigation

[简体中文](0.2.24.zh-CN.md)

Administrators can upload PNG, JPEG or WebP images under **Site & services → Site information → System logo**, preview the choice, save it or restore the default icon. The server validates non-animated images up to 5 MB / 16 megapixels, removes source metadata and produces a PNG no larger than 256 pixels per side. The saved icon appears in workspace navigation, sign-in and non-document browser tabs; document tabs retain their existing format/title icons. Failed saves retain the chosen image for retry, and saving branding does not discard unsaved site-name fields.

The approved nullable `settings.site_logo` addition uses the existing current-DDL reconciler without a compatibility-generation bump. Historical NULL retains default branding. Existing settings, content, permissions and document-startup cache format are preserved; there is no `account_settings` branding record or historical conversion. Administrator permission, same-origin checks, site-settings revision checks and transactional security audit protect writes. Unknown or damaged Logo records are preserved and rejected.

Update server and Web together after backing up databases, file volumes and deployment configuration. Previous binaries' existing structure review rejects the new field; preserve all later data for a separately reviewed recovery rather than dropping the column or restoring an old backup over later writes. GitHub assets and native Linux amd64/arm64 Docker Hub images are the release artifacts; publishing them does not deploy a running site. The browser extension remains 0.2.10.

Spreadsheet comment navigation now accounts for frozen pane pixel dimensions, including hidden rows/columns and unequal dimensions. It preserves the selection, document bytes and collaboration state. See [Logo acceptance](../verification/site-logo-2026-10-28.md) and [spreadsheet comment acceptance](../verification/sheet-comment-freeze-2026-10-28.md).
