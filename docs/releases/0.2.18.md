# Doca 0.2.18 — SVG capture and shared comment scrolling

[简体中文](0.2.18.zh-CN.md)

Browser extension **0.2.5** converts static linked and inline SVG to PNG while retaining transparency. Unsupported, unreadable or unconvertible images become readable placeholders at their original positions, with a reason and the original HTTP(S) source link. Other text and images continue saving. Hidden tracking images are excluded. Authorization, quota and storage failures still stop saving; staged tasks keep their frozen body, manifest and request ID for retries.

Rich-text comments and document content now share one vertical scrollport at desktop and compact widths. Scrolling over comments moves the document, and cards remain aligned to their anchors. Reply drafts, comment navigation and long reply threads continue to work without an independent comment scrollbar or idle content writes.

Update the server and Web together, then download/reload extension **0.2.5** and refresh the source webpage. Start a new capture for a historical failed task. The owner approved preserving historical tasks, saved documents and already uploaded images without automatic conversion or resubmission; old tasks retain their existing expiry and manifest requirements. Capture protocol v1, raster asset formats, database structure, comment anchors and stored document/queue formats are unchanged. Rollback needs no data conversion. Preserve all database/file volumes and the credential master key, following the [database upgrade contract](../database-schema-evolution.md) and [browser queue rules](../browser-assistant.md).

SVG scripts and event handlers are removed before local rasterization; external dependencies, embedded HTML, animations and unsupported rendering use placeholders. SVG input transfer is limited to 32 MiB and PNG output to 4 MiB, a 4096-pixel longest edge and 16 million pixels. Existing bitmap compression and animation limits still apply. See the [capture acceptance record](../verification/browser-extension-svg-2026-10-25.md) and [comment scroll acceptance record](../verification/rich-comment-scroll-2026-10-25.md).
