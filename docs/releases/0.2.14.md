# Doca 0.2.14 — Browser toolbar controls

[简体中文](0.2.14.zh-CN.md)

Browser extension **0.2.3** replaces the webpage capture rule's native browser picker with Doca's shared dropdown. The menu supports mouse and keyboard selection, closes on outside clicks or Escape, and remains visible outside the scrolling confirmation bubble. Escape closes the open menu before the bubble.

The toolbar now has a collapse/expand button in the same column below Settings and a more visible drag handle. The collapsed toolbar retains its handle and expand button, so it can still move vertically. Collapsing and expanding preserve its vertical anchor.

The toolbar reads its existing local position cache before becoming visible. Refreshing, opening another page and restarting the browser restore the saved position. A failed cache write shows a retry hint and retains the previous stored value. Position storage uses the existing key and numeric format, without conversion or a server/database change.

After updating Doca, download the extension again from Browser assistant settings, replace the unpacked files, reload extension 0.2.3 in Chrome / Edge and refresh open webpages. Updating the server alone does not update installed extensions.

No database, editor SDK, authorization or AI queue format changes are introduced. Preserve existing data and browser stores; rollback continues to follow the existing queue-disable contract. See the [control verification](../verification/browser-extension-controls-2026-10-24.md).
