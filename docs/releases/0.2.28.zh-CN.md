# Doca 0.2.28 — 用户组与统一权限管理

[English](0.2.28.md)

新增组创建、头像、角色、名称/链接邀请、接受邀请、退出、交接与解散。组授权接入文档、知识库、知识册和共享文件夹的邀请协作者与成员管理页面。共享文件夹改用文件夹分享图标，组入口位于其下。

同组成员计入相关用户查询关系；组搜索由管理员配置，可按用户覆盖，默认仅所在组，另有权限交集及所有有效组两档。搜索不开放外部成员列表。退出、移除或解散即撤销该组来源，并重新检查已连接会话及知识查询权限。

个人与组授权统一使用紧凑的两行公共组件，支持权限修改、子文档范围和删除气泡确认。个人授权明细复用相同操作，组来源继续独立生效。组成员默认展示三个头像，可查看用户卡片并通过「更多」浮层展开；高于个人授权的组生效角色用加粗蓝色标明。

文档树拖动调整时，从保存到目录刷新完成持续显示加载提示，处理中阻止再次拖动，成功或失败后均解除状态。

经明确批准新增八张表，保持 schema 代际。原有数据和授权保留，七张组/授权表为空，独立组搜索策略明确初始化为仅所在组。解散满 24 小时后由启动/每小时任务分批清理关联，保留资源、失效记录和审计。升级前备份数据库、附件、配置和凭证主密钥，所有实例及 Web 同步升级。降级须另行评审数据保全与恢复，不得删除新增表或用旧备份覆盖后续写入来绕过旧版本审查。见[规则](../user-groups.zh-CN.md)、[升级约定](../database-schema-evolution.zh-CN.md)及[验证记录](../verification/user-groups-2026-10-30.md)。

发布目标为 GitHub 附件与 Docker Hub 原生 Linux amd64/arm64 镜像，不会自动更新运行中的站点。全新安装可使用 `doca-compose-v0.2.28.yaml`，已有部署保留原部署身份和持久卷。从更早版本升级仍须遵守 [0.2.27 渲染器及配置要求](0.2.27.zh-CN.md)。
