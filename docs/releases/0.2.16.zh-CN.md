# Doca 0.2.16 — 浏览器助手上下文

[English](0.2.16.md)

浏览器助手打开时先按当前收录规则校验上次会话。规则更新后，旧版本规则绑定的会话仍保留在 Doca，插件为当前选中的规则打开新输入器，不再错误地提示会话访问权限变化。其他授权和网络错误继续明确提示，初始化失败后可重试。

新消息附加的网页会进入会话的「操作过的资源」，显示原网页标题，点击在新标签页打开。Doca 网站与插件都能查看，同一网址反复处理只保留一个关联条目。这些活动记录不授予文档访问权限。新浏览器会话在首条消息被接收时，根据请求、网页标题和域名生成标题；后续消息、用户手动命名及历史标题保持原样。历史会话列表和会话标题栏中的来源文字改为带无障碍说明的浏览器图标。

富文本评论区展开时，上下跳转和 AI 按钮也保持在页面最右侧，覆盖窄屏布局。

更新 Doca 后，重新下载并加载浏览器扩展 **0.2.4**，再打开助手。数据库结构、收录与认证协议、队列和会话持久格式及已有内容保持原样；不转换、删除或回填历史会话、待发送消息和网页记录。既有旧队列与认证处理约定继续见[浏览器助手说明](../browser-assistant.zh-CN.md)。
