# Doca 0.1.8

[English](0.1.8.md)

## 变更

- 为导航增加独立侧栏更多下拉位置 `web.leftMore`，为可选全局插件操作/视图增加 `global.leftMore`。原有 `web.more`、`global.more` 继续属于右上角。
- 修复嵌套绝对定位导致的空更多弹框；右上角导航和插件操作以图标显示，悬浮时在下方显示名称。
- 为右上角导航、更多、语言和账号操作增加下方悬浮名称。
- 导航设置区分两个更多位置，并在预览中显示对应样式；预览不挂载可执行插件扩展。
- 紧凑侧栏下拉仍保留名称；各更多位置在过滤后导航与插件贡献都为空时隐藏。支持外部点击、Esc、路由切换关闭；触发菜单关闭后，插件弹框继续保持。

## 配置与插件集成

新位置可选，插件必须显式声明。内置用户导航可配置到任一位置。现有配置不迁移，旧插件不会自动获得新位置。既有溢出和去重规则保持，允许同时显式放入两个更多菜单。

不新增数据库迁移或自动转换。回退到不支持侧栏位置的宿主前，先撤回并发布 `web.leftMore` 配置及对应插件声明；旧宿主不会自动转换未知位置。

新增位置类型已经包含在 GitHub 源码中。本版在 GitHub 与 Docker Hub 发布宿主；当时公开 npm SDK 仍为 `0.1.5`，不包含这些新增源码能力。

## 分发

GitHub 标签：`v0.1.8`。Docker 镜像：`docker.io/smartdoca/doca:0.1.8` 与 `docker.io/smartdoca/doca:latest`，支持 Linux amd64 和 arm64。

GitHub Release 包含 Web 资源和 SHA-256 校验文件。使用 `DOCA_ASSET_BASE` 时，按原目录结构解压并发布 `assets` 目录。
