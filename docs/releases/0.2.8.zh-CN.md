# Doca 0.2.8 — 编辑器修复与浏览器助手可靠性

[English](0.2.8.md)

本版本整合编辑器、评论、浏览器助手和 AI 消息恢复修复，发布证据见[验收记录](../verification/issue-tracker-2026-10-21/npm-direct.md)。[GitHub Release](https://github.com/workhold/doca/releases/tag/v0.2.8) 和 DockerHub `0.2.8`/`latest` 已发布并核验，见[最终回执](../verification/issue-tracker-2026-10-21/release.md)；生产站点未由本轮升级。

五种编辑器直接引用正式 npm：Canvas **0.5.14**、Sheet **0.2.11**、Slate **0.4.25**、Markdown **0.4.4**、Slides **0.3.0-alpha.4**。全部编辑器本地补丁已移除，发布检查拒绝本地候选、版本范围和生效的编辑器 patch。Mastra memory 仍保留独立且必要的反射修复，未扩大 SDK 升级范围。

表格默认缩放仍为 **100%**，对应默认行高/列宽增加 10% 至 **21.78/87.12**。右下角滑块和加减调整按网站、账号、文档保存到浏览器，刷新后恢复。已保存尺寸及手动行列调整保留；用户明确批准未记录默认尺寸的历史附加/恢复表采用新默认。手动行列尺寸继续协作。

更新还包括画布连线、容器、便签、标题、原生键盘事件和最小表格撤销；表格超链接焦点、预览销毁、复制、下拉删除和共享筛选；富文本标题、流程图文字与 DOCX 样式。五格式图库、自动评论分页、评论上传/发送反馈及草稿、实际占据页面宽度的侧栏均经过网站检查，评论按键不会误改选中正文。

浏览器助手保留多套收录方案和一个默认方案，与网站共用 AI 对话界面。IndexedDB sender 保留原消息 ID、明确继续、方案隔离及 accepted/withdrawn 墓碑。速记明确选择已授权的既有富文本或 Markdown 目标，追加纯文本且不调用 AI；丢响应重放使用同一回执，不重复追加。五分钟 ticket 仅属于当前进程，关闭视图丢弃临时输入/目标。

Canvas 视图和新建连线/便签样式属于按网站、账号、文档隔离的个人偏好；只影响未来交互创建，既有内容和明确 API/AI 属性保留。未知/坏偏好记录不动。画布 PNG 导出交付可下载文件，大图检查使用有界预览并保留原图字节。

镜像继续包含 Chromium、Office 和字体，以支持 PDF、画布截图和文件预览。构建后移除类型声明、SQLite 编译输入和非当前平台的预编译文件；公共依赖与五种编辑器分别成层，CI 使用分架构 registry 构建缓存。首次换层仍需下载，后续未变化层可复用。隔离实验及口径见[镜像记录](../verification/issue-tracker-2026-10-21/image-size.md)，不把实验下载量当作每次实际更新的固定大小。

## 升级与恢复

服务器数据库结构、兼容代际、文档 codec/schema、不可变 baseline、checkpoint 及协同 ACK/消息身份与0.2.7相同。不新增服务器迁移、历史文档转换或收录方案合并。[0.2.7](0.2.7.zh-CN.md#升级与恢复)的浏览器助手认证和结构要求继续有效。

**用户已两次明确批准 AI 浏览器队列存储变更。** 新消息使用独立 IndexedDB `doca-ai-pending` version 1 / `entries`，按目标 Doca origin、登录账号、连接和原消息 ID 隔离，扩展保留明确方案修订。完整 payload 和来源哈希经校验，转换在事务提交后才成功。accepted/withdrawn 墓碑保留；未知版本/记录和存储失败保留并拒用，不降级为 localStorage 或仅内存发送。

原0.2.7 localStorage 队列只读，不合并、不删除、不自动重放。每条已识别旧项须明确继续/撤回并选择当前设置，已接受任务只核对而不重复捕获或提交。**升级或回退前停止发送，并关闭全部旧网站页和扩展。不支持新旧 sender 同时运行**，因为旧 sender 看不到新墓碑。回退停止新 sender，保留新旧存储、墓碑和全部后续数据，不回写旧队列或自动启用旧 sender。缺少安全停用 sender 能力的旧程序不能恢复队列发送。详见[获批存储与恢复方案](../verification/issue-tracker-2026-10-21/ai-pending-idb.md)。

Canvas 个人偏好使用独立 version1 记录。无记录保持当前行为，未知版本或坏 JSON 不读取、不覆盖；视图变化不进入正文协同/历史。回退停用偏好读取，不删除记录或转换正文。

表格缩放使用独立 version-1 浏览器记录；缺记录采用 100% 且打开不写，未知/坏/额外字段记录保留且拒用，无法写入时只在当前视图生效，匿名不持久化。回退停用读写并保留记录和内容。已存默认尺寸、手动行列尺寸、baseline/seed/checkpoint/update/epoch 不迁移或回填；仅未存默认尺寸的工作表按批准采用新显示默认值。

保留数据库、文件卷、设置、凭证主密钥及后续写入，部署匹配的服务器、Web 和扩展产物。保留上一版制品并遵循已审查的恢复要求；本版本不定义通用数据库降级流程。
