# Doca 0.1.10

[English](0.1.10.md)

## 变更

- 通过 `storage.credentials.v1` 提供宿主管理的插件凭证：服务端加密创建/读取/元数据、修订号更新/删除、插件身份和安装代次隔离，以及卸载清理。环境提供共用 `DOCA_CREDENTIAL_MASTER_KEY`；缺失、无效或不匹配时明确失败，不生成或替换密钥。
- SDK 0.1.9 / 契约包 0.1.7 增加素材集。素材可属于零个或多个集合，搜索与 AI 检索分别返回素材/集合组，独立标签和分页。集合元数据轻量，成员另行查询，使用前复核权限和修订。
- 统一模板和素材浏览：来源、标签两行，默认全部，来源可多选。筛选图标打开关键词/智能搜索及排序，提交后搜索词保留且可清除。卡片展示预览和来源，保留空白文档创建。
- Compose 转发数据库、Redis、云文件存储和凭证密钥。后端仍由部署方管理，管理员界面只展示存储状态，不接受后端凭据。
- 素材/集合任一查询拒绝前等待两组结束，避免提供者释放后另一组仍使用数据库连接。
- 宿主版本报告由应用模块持有，本地插件 ZIP 不进入 Git。
- 存储验收示例更新至 1.0.5，使用 SDK 0.1.9、materials.v2 和显式集合能力。

## 不兼容部署要求

数据库基线为 `doca-2026-10-03-credentials-v2`。0.1.9 及更早数据库明确拒绝，不迁移、转换、自动补表或删除数据。保留旧部署、数据库和存储用于回退，新版使用新空数据库及独立持久存储；回退时新部署数据另行保留。

素材提供者实现 `materials.v2`，声明 `version: 2`，并显式声明 `collections`（方法或 null）。不适配 `materials.v1`。已有文件、文档及资源引用保留，模板继续使用 `templates.v1`。

插件声明 `doca.storage: "host"`，SDK 范围覆盖 0.1.9，最低版本满足已有 0.1.7 安装下限。素材提供者针对 SDK 0.1.9 重建。托管凭证插件声明公开凭证 token；部署在重启与副本间保留相同主密钥。插件变化后手动重启全部实例。

## 验证与限制

默认测试在 182 个文件中通过 1193 项，跳过 3 项环境条件测试；71 项定向 PostgreSQL/Redis 检查全部通过，含 3 项条件用例。TypeScript、Web 生产构建、独立 SDK JavaScript/声明及打包 npm 消费者通过。源码浏览器验收使用隔离数据，覆盖素材/模板筛选、智能搜索、预览及窄屏筛选位置。凭证验收使用隔离数据库和合成密钥，见[记录](../plugin-credential-acceptance.md)。

发行制品验证包括打包/公开 npm 消费者及两个 Linux 架构的新数据库容器启动，最终结果记录于发行清单。不声明真实外部 AI、邮箱、SSO、Webhook、S3、CDN 服务或原生移动构建已验证。发行检查不使用生产用户数据。
