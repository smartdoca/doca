# Doca 0.1.18

[English](0.1.18.md)

本版统一发布在线表格子包对接与当前工作区的其他改动，包含 0.1.16、0.1.17 已发布修复。表格使用已发布的 `@smartdoca/sheet@0.2.0-rc.19`，插件 SDK 仍为 0.1.10。

## 改动

- 表格工具栏「数据验证」与「插入 → 下拉列表」使用各自入口；插件元素插入接入原生菜单扩展，保持当前选区、只读权限和原生事务；从阅读切回编辑时立即刷新工具栏能力显示。
- 知识册失败后继续原运行及冻结配置，保留已完成节点、失败记录与无关分支；续跑前核验来源清单、内容版本、哈希和当前权限。画布增量更新，切换运行防止旧响应覆盖新选择，隐藏页面暂停轮询。
- 知识册阅读目录使用真实 Markdown 标题，长标题完整换行；溯源图支持证据与判断分组、重复连线合并。新生成内容分批处理并检查知识点覆盖、章节标题和 Mermaid 图示保留。
- 知识册网页来源使用配置的抓取服务，支持 HTML 章节定位，校验公开地址、重定向与响应大小；搜索管理后台可以清理错误的嵌入维度设置。
- 富文本原生流程图、思维导图可通过工具栏插入，并使用整块评论与 AI 引用。AI 修改原生图示数据时同步失效派生预览；上传显示实际传输进度，工具栏悬停提示保留选区。
- Web 路由、预览和部分大型组件延迟加载，Markdown 预览不再提前加载 PDF 转换依赖。静态资源按请求协商 Brotli/gzip 并使用有界缓存；CAD 资源可通过生产静态路由读取。PDF 中文字体改用保留完整字形的 WOFF2。
- 登录提供商图标、文件预览、AI 面板与窄屏布局改善；移除已停用的仓库内编辑器压缩包，使用锁定的 npm 制品。

## 验证与限制

全量回归 267 个文件通过：2,648 项通过、3 项环境测试跳过。冻结依赖安装、TypeScript、Web 生产构建和双语文档检查结果见发行验证附件。

rc.19 公开类型和 Yjs/model/XLSX 文件与 rc.18 字节一致。已有隔离表格验收覆盖中英文入口与只读禁用；宿主回归覆盖表格会话、稳定锚点、工作表、行列尺寸、引用与 XLSX 导入。已有图示、工具栏、知识册和 PostgreSQL 验收资料保存在 `artifacts/`。镜像的最终平台、启动、资源摘要与静态压缩结果见发行验证附件。

所有新增验证使用隔离数据，未编辑用户文档或生产数据库。真实来源上的模型知识深度、移动端真机、生产备份恢复和云端配置仍需各自验收。0.1.17 记录的 PostgreSQL `assets.purpose varchar(16)` 图片候选长度限制未修改，相关生成／修订用例不宣称通过。

## 部署与回退

数据库基线仍为 `doca-2026-10-09-history-storage-v1`。本次没有新增兼容适配、旧格式转换、数据库迁移或用户数据清理；现有历史读取、严格基线校验和显式离线升级命令保持原规则。0.1.17 部署更换镜像时保留数据库、文件、配置和凭证主密钥。更早基线遵守 [0.1.15 升级要求](0.1.15.zh-CN.md)。回退前停止写入并备份数据，旧发行制品与 Git 标签保留。

- GitHub 标签 `v0.1.18`，附 Web 资源、逐文件摘要、校验和及验证清单。
- Docker `docker.io/smartdoca/doca:0.1.18` 与 `latest`，Linux amd64、arm64。
- npm 表格 `@smartdoca/sheet@0.2.0-rc.19`；插件 SDK `@smartdoca/plugin-sdk@0.1.10` 无导出变化。
