# 历史变更：插件独立业务库

历史记录：本每插件独立库方案已在 0.1.25 发布。[0.1.26](0.1.26.zh-CN.md) 改为一个共享插件业务库，须卸载重装，不迁移数据。
[English](pending-plugin-database-isolation.md)

2026-10-14 的原始状态：当时工作区候选尚未发布或部署。当前发行状态以上方说明为准，下列验收结果保留原范围。

插件 SQL 业务表改为宿主管理的每插件独立库：SQLite 独立文件，或显式配置的 PostgreSQL 独立库及受限角色。公开 SDK 接口不变。核心文档、用户、权限、普通用户文件和平台管理的插件元数据保留原存储位置。

不迁移既有插件数据。先在旧宿主正常卸载全部外部业务插件，停止全部实例，部署后重装并重启。旧版卸载会删除插件私有业务记录、加密凭证和私有对象，随后须重新配置和绑定账号。新宿主拒绝残留旧安装及业务表，不自动删除。详见[升级、恢复与存储约定](../plugin-database-isolation.zh-CN.md)。
