# Doca 0.2.20 — Best-effort webpage capture

[简体中文](0.2.20.zh-CN.md)

Browser extension **0.2.7** and the matching server save readable content when conversion is incomplete. Failed images and unsupported embedded media keep placeholders; conversion warnings no longer abort an entire capture. Unexpected parser failures retain the original Markdown as literal text and preserve uploaded images. The current request returns its conversion warnings, and the extension lists them beside the saved-document link.

Official npm dependency **@smartdoca/slate 0.4.26** fixes escaped citation brackets, escaped image descriptions, dollar prices and dollar-containing links being mistaken for mathematical source. Multiline image descriptions are collapsed before generating Markdown. Real formula/HTML degradation still produces a visible document notice.

No database, persisted capture payload, protocol version or document schema changes. Diagnostics are transient and are not stored as a task report. An interrupted response can be retried idempotently; a completed task returns the existing document without recreating it or claiming to replay historical diagnostics. Failed historical tasks must be recaptured; their original expiry remains. Preserve saved documents, uploaded assets and subsequent writes during rollback. Authorization, quota and storage-write failures still reject rather than report success. Update server and extension together to obtain the new capture behavior.

See the [Annual Reviews acceptance record](../verification/annualreviews-capture-2026-10-26.md).

The extension also checks the configured server for newer packages and links to its download page. Doca displays the versioned filename `doca-browser-assistant-0.2.7.zip`; failed checks do not affect capture or claim the package is current. Existing unpacked extensions require one manual update/reload before receiving future reminders. No automatic installation or forced downgrade is introduced. See [update notification acceptance](../verification/browser-extension-updates-2026-10-26.md).
