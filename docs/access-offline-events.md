# 权限申请、本地副本与事件同步（2026-09-11）

## 文档访问与待办

当前 visibility 语义为：public=公开、authenticated=登录可读，requestable=可申请，invited=仅受邀。继承模式仍遵从上级 ACL；申请开关只在独立设置时开放未授权申请入口。

可申请只暴露标题和申请入口，不授予正文/附件/搜索权限。不可见的未授权访问与不存在均为 404。已可读用户可申请更高权限。用户必须登录且 active 才能申请；匿名用户始终不能评论。

- GET /api/v1/resources/:id/access-preview：最小申请预览。
- POST /api/v1/resources/:id/access-requests：role=reader/commenter/editor/manager。
- GET /api/v1/me/access-requests：自己的申请及当前有管理权的待处理申请。
- POST /api/v1/me/access-requests/:id：decision=approved/rejected/cancelled。
- 原 me/invitations 接口继续处理协作邀请，并统一显示在 #/todos。

申请创建与决定均在短事务内串行，去重待处理申请。审批重新检查当前管理权和申请人状态；不能自己审批、越权审批或重复决定。通过直接产生已接受授权，不再次邀请；不降低已有直接授权。拒绝/撤回不会改变权限。退出可见范围后，申请记录不再暴露原文标题。

## 富文本本地副本

之前仅有页面内存队列，现在富文本接入原生 IndexedDB `doca-offline-v1`。不是把 JSON 重建为新 Y.Doc：缓存保留原始 Yjs checkpoint 和实际本地增量及原消息 ID。

缓存按浏览器 origin、用户 ID、文档 ID、codec 隔离。一次读写事务合并 checkpoint 与 pending 队列，因此同账号多页不会相互覆盖本地副本。只有本地内容事务进入待同步队列；远端增量只更新副本。先提交本地持久事务再发到服务器；精确匹配的服务器 ACK 到达并清理 IndexedDB 后才完成出队。服务器拒绝或存储失败会暂停编辑，保留恢复文件入口。

已通过资源元数据授权检查后，编辑器先从本地副本初始化，再 join/vector 同步，不等待首个 sync-response 才渲染缓存内容。断线已打开文档可继续文字编辑；网络失败不再把当前编辑器卸载。重连补拉远端变化后按原 ID 重放未确认增量。历史回滚仍是在原 CRDT 谱系产生编辑，不重建缓存。

边界：

- 此轮只接入富文本；Excel 的不可变 baseline/epoch 缓存还需单独接入，不能套用正文缓存。
- 不是完整 PWA：冷启动应用、登录/资源元数据验证仍需网络，未部署 Service Worker 离线应用壳。不能宣称断网关闭浏览器后可完整重开站点。
- 上传、评论、@用户查询、权限设置需网络，不进入正文离线队列。
- 本地缓存是已授权下载副本，不是服务器最新 ACL；重连后服务端重新校验权限，不能靠本地缓存获得服务器授权。用户 ID 隔离而非设备级加密，共用设备应清理浏览器站点数据。
- 当前富文本协议尚无完整 epoch 协商；不支持服务器重建/恢复到不相关谱系后盲目同步。
- 浏览器可能清理站点数据，存储不足会报错，不能承诺无限期本地持久性。

## Hook 事件同步

本轮提供持久的拉取式事件流，不是外部 Webhook 推送服务。

`GET /api/v1/admin/integration-events?after=0` 仅管理员可用，每次最多 100 条，返回 items、单调 cursor、hasMore。消费方成功处理后保存 cursor，下次续拉；按 id 去重。序号在业务事务内锁定分配，不用毫秒时间戳随机 ID 排序，以免并发事件漏读。

事件随业务提交：文档/知识库创建、重命名、权限变化、移动、回收/恢复、互动等核心事件；notification.created 携带通知 ID、接收用户、事件类型、资源标识和跳转路径；申请/邀请决定也有事件。无文档正文、登录凭证、资产密钥。回滚事务不留下事件。

管理员 Hook 页面可查看事件及接入方式。尚未提供：独立机器凭证、外部 HTTPS 签名推送、重试投递/死信、订阅配置、自动保留期清理。capabilities.integrationEventStream=true，hooks 仍为 false，避免将事件流冒充完整推送能力。

## 本轮验收

91 项测试、类型检查、生产构建通过。隔离内存数据库与 Chrome 浏览器验证：3×5 选择器高亮 15 格；断网输入持久保存、关页后未同步 ID 不变；阻断 WebSocket 时先恢复本地正文；联网后重放并清空精确 ACK 队列；同账号双页编辑同步；静置 60 秒零新增内容提交；用户卡片 hover/离开关闭；原子文档引用新页打开且原页不跳转；权限申请→待办跟进→管理者审批→只读页面与升级申请入口。权限测试包含“待接受管理邀请不能被低级权限申请隐式激活”。浏览器验收没有使用用户文档。
