# 统一存储改造与本地浏览器验收

验收日期：2026-10-03。实现方案见 [统一存储实现](unified-storage-implementation.md)。仅使用隔离测试数据库、目录、测试账号及自建验收插件；没有连接生产库、编辑用户文档、迁移或清空旧数据。源码 SDK 0.1.7 尚不代表 npm 已发布。

## 环境与范围

两个独立宿主进程共用 PostgreSQL 17、Redis 7 和持久化文件存储；实例插件缓存目录分开。浏览器分别访问 A `http://127.0.0.1:39230` 和 B `http://127.0.0.1:39231`，服务仅绑定本机。数据库使用隔离 schema `doca_browser_storage`，Webhook 使用独立验收数据库。自动化测试各自创建独立数据库或 schema，Redis 条件测试使用独立键前缀及 DB 15。

安装了两个本仓库构建的示例：`example.storage` 1.0.3（公开 SDK 的私有数据库、私有对象、常规文件、内容源、模板与素材），`example.elements` 1.0.0（富文本/表格插件元素）。邮箱等独立业务插件不随宿主安装，也没有凭现有 SDK 测试宣称其已验收。

以下“通过”仅指表内写出的步骤。读取管理页面不等于验证真实第三方服务；单个编辑器的创建、编辑、协作及重开不等于穷举所有菜单和导出格式。

## 本次验收发现并修复

1. Markdown 在收到权威 checkpoint 前建立本地结构元数据，导致第一次文本编辑携带无法提交的 CRDT 依赖。改为空副本接收 checkpoint 后再建立公开 SDK 会话；不转换已有文档、协议或本地待发送数据。新增实际后端交换回归测试。
2. 同版本卸载重装后，仅比较代码版本/哈希会漏掉安装代次变化。实例保存启动时的代次，管理清单同时比较代次；旧实例仍提示重启。仅同一有效代次的启停/升级可取消；初次安装、已卸载或更换代次不通过取消恢复旧数据。
3. 已移除的宿主模板管理页仍有导航入口。移除失效入口；模板由公共 SDK 注册及创作选择器提供。
4. 内容源创建递增刷新计数，但加载 effect 未依赖它。补上依赖，并通过第二条订阅的即时显示复测；补全中英文类型标签。
5. 验收插件曾硬编码 Web 版本，导致版本检查拒绝。示例构建现从 manifest 自动生成 Web 版本，并校验 package 版本；用新不可变版本 1.0.3 验收，没有覆盖已发布同版本 ZIP。
6. Redis 条件测试原先用同一个数据库运行时句柄建立两个宿主，触发重复公共注册。测试改为两个独立服务运行时句柄，共用测试执行器与隔离数据；生产浏览器验收使用两个独立进程和连接池。

## 尚未完成的外部与专项验收

- 真实 AI 生成、知识整理/OCR、问答回答与实际供应商用量结算：验收环境没有模型地址/密钥。已检查缺配置反馈，自动化覆盖不能替代真实服务验收。
- 邮箱独立业务插件、验证码网关、SSO、真实 Webhook：未提供对应插件/测试账号/服务端。未使用真实用户凭据或邮箱。
- 真实 S3/CDN 上传下载、跨主机共享盘/容器滚动部署：本地采用共享目录；S3 条件写入和完整性使用自动化模拟，不能视作真实云端联调。
- 手机 App/原生 WebView、演示文稿全屏放映，以及各编辑器全部格式化/导入导出菜单：未完成专项验收。

旧基线、version 1 插件清单、旧存储配置和旧 SDK 范围明确拒绝，不迁移、不双读写、不删除旧数据。部署新版需要新空数据库和符合 SDK 0.1.7 的插件。全部实例仍需运维人工逐个重启。
